2. Product release pipeline — production पहले

Institute / Research

समस्या, intended user, sources, requirements और differentiator दर्ज करें।

Factory / Build

चलने वाला tool, sample output, error handling, privacy/security notes और reproducible build बनाएं।

QC / Dispatch Gate

Use-case tests, limitations, accessibility/security checks, release ID और issue log दर्ज करें। QC claim test evidence पर आधारित हो।

Public Showroom / Sale

Product-specific screenshot, demo video, usage guide, price, support/refund terms और enquiry/checkout path दिखाएँ।

  1. Release checklist: product ID + version + intended use + demo + screenshots + instructions + price + limitations + support contact.
  2. Feedback loop: review → issue triage → improvement ticket → new version → change log.
  3. Release states: IDEA → RESEARCHED → BUILDING → DEMO READY → QC PASSED → PUBLISHED → MAINTAINED.
