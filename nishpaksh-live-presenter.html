Live pipeline

  1. Question received
  2. Context + canonical records retrieved
  3. Evidence and verification state classified
  4. Answer composed with provenance
  5. Authorized voice selected
  6. Authorized presenter selected
  7. One synchronized lip-sync render
  8. Runtime health checks
  9. Live presentation + archive

Integrity boundary

Philosophical / identity statement ≠ independently verified scientific evidence.

Author-source material can be presented faithfully as author-source. Empirical or scientific claims require appropriate sources, reproducible tests, and independent verification before a VERIFIED state is allowed.
