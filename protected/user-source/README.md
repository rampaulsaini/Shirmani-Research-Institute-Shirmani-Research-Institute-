# Protected User-Source Archive

This directory is the preservation boundary for explicitly captured original user material.

## Rules

1. Store only actual source material.
2. Preserve source bytes exactly.
3. Do not silently normalize, translate, correct, shorten, merge, or overwrite originals.
4. Keep derivatives outside this boundary and link them to stable source IDs.
5. Missing historical material remains missing; never reconstruct it from memory or inference.

An empty archive is valid infrastructure state. It does not mean historical conversation material has been recovered.
