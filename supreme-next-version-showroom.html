Production cycle

1. Institute: define customer need and product specification.
2. Factory: implement a usable feature and package documentation.
3. QC / Release gate: run reproducible tests and record pass/fail and limitations.
4. Showroom: publish only actual features, genuine price terms, product visuals, demo and support details.

No invented prices, guarantees, ratings, endorsements or sales claims. These prototypes do not yet have configured prices or MP4 demo videos.
