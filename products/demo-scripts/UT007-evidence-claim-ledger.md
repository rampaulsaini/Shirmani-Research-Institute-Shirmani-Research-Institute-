# UT007 — Evidence Claim Ledger demo script

Duration: 60–90 seconds.

1. Open `products/micro/evidence-claim-ledger.html`.
2. Enter one narrow claim, for example: “The report states that the programme began in 2024.”
3. Add the report title and official URL.
4. Choose SOURCE-BASED and record what still needs checking.
5. Select Create record and show the JSON preview.
6. Demonstrate Download JSON and Download CSV.
7. Explain that the tool organizes evidence metadata; it does not fetch or validate sources and does not independently verify a claim.
8. A real independent review must record its reviewer, method, evidence and date before a claim is described as independently verified.

Voice-over: “Evidence Claim Ledger helps organize a claim, its source, evidence state and review notes into a portable record. It works locally in your browser. It never claims a source was checked when it was not.”
