# Digital Product Factory Blueprint

## Product lifecycle

DISCOVER → SPECIFY → PRODUCE → QC → PACKAGE → SHOWROOM → ORDER → PAYMENT EVIDENCE → DELIVERY → CUSTOMER FEEDBACK → IMPROVEMENT

## Product definition

A digital product is a customer-visible artifact with a stable identity, useful function/content, version, quality state and delivery route.

## Production truth

- Workflow run ≠ product
- Catalog identity ≠ finished customer value
- Concrete artifact ≠ completed sale
- Payment route ≠ completed payment
- QC pass ≠ independent scientific verification

## Commercial release gate

Release only after the artifact opens correctly, the description matches the artifact, the price/offer is explicit, the payment route is identifiable, and the delivery procedure is defined.
