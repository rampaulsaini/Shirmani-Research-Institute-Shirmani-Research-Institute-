# Product Blueprint Studio — Usage Guide

- **Product ID:** SRI-TOOL-009
- **Artifact:** `products/micro/product-blueprint-studio.html`
- **Type:** Free, client-side browser tool
- **Version:** 1.0.0
- **Privacy:** Inputs are processed in the current browser page; the tool has no backend or external AI integration.

## How to use
1. Open the product page from the public showroom.
2. Enter a product/tool name and intended user.
3. Select the product type and current stage.
4. Describe the problem, core features (one per line), and known limits.
5. Choose **Generate blueprint**.
6. Review scope, user journey, acceptance criteria, demo outline, showroom copy, and release checklist.
7. Copy the brief or download it as Markdown.
8. Treat the result as a planning draft; run real product tests before release.

## Demo script
1. Introduce the problem of turning a vague product idea into an actionable brief.
2. Fill the form with one realistic example.
3. Generate the blueprint.
4. Show the acceptance criteria and demo outline.
5. Download the Markdown file and open it.
6. State the limitation: this tool drafts plans; it does not build, deploy, independently verify, or sell the described product.
