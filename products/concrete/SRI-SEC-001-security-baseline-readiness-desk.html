Use: asset inventory · access control · secrets · dependency hygiene · backups · incident response · privacy · release gates

1. Scope and authorization

Only assess systems you own or are explicitly authorized to test. This tool performs no scanning, exploitation, network requests or account changes.

2. Readiness checklist

Mark an item only when you have inspected evidence. “Unknown” should remain unchecked.

4. Release boundary
