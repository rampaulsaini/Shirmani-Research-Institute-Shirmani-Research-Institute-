# P101 — SEO Launch Checklist

## Discoverability
- [ ] One clear primary topic
- [ ] Descriptive title and meta description
- [ ] Canonical URL
- [ ] Useful headings and internal links
- [ ] Descriptive image alt text
- [ ] Mobile-readable layout

## Trust & conversion
- [ ] Author/source identified
- [ ] Claims separated from evidence
- [ ] Price and limitations explicit
- [ ] Order/delivery route works
- [ ] One clear call to action
- [ ] No fabricated testimonials or results

## Final test
Test every link in a private/incognito window and record the date.
