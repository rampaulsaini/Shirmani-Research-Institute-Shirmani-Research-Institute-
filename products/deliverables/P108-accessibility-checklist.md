# P108 — Digital Accessibility Checklist

- [ ] Keyboard navigation works
- [ ] Visible focus indicator exists
- [ ] Images have meaningful alt text or are decorative
- [ ] Form controls have labels
- [ ] Heading order is logical
- [ ] Text remains usable when enlarged
- [ ] Links describe destinations
- [ ] Audio/video has captions or transcript where needed
- [ ] Motion can be reduced where needed
- [ ] Errors explain recovery
- [ ] Essential information does not depend only on color

Record device, browser, date and unresolved issues before publishing.
