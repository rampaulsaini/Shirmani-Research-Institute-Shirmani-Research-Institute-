MULTI-LAYER WORK PLAN

🧩 Product materialization

Convert queued identities into concrete artifacts. A workflow run is never counted as a product.

Measure: concrete artifact + product ID.

🎨 Visual identity

Every concrete product gets its own scalable master visual route with logo, identity text, short description and upper-right long-description QR.

Measure: visual manifest coverage.

🎬 Media presentation

Connect demo-video, interactive demo and VIP presentation routes where assets exist; never claim a real MP4 when only a route exists.

Measure: media manifest coverage.

⭐ Customer improvement

Reviews and ratings feed product-quality improvement. They are customer signals, not scientific verification.

Measure: feedback → improvement actions.

🛍️ Commercial readiness

Keep price, offer, guarantee, packing, order intent and dispatch state separate. No fabricated sale or dispatch.

Measure: sale-ready passport fields.

⚙️ Continuous automission

Scheduled work can continue without an open chat, subject to GitHub Actions availability, permissions, quotas and workflow health.

Measure: completed production cycles.
