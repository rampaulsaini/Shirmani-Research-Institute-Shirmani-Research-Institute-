## Production rule

A workflow run is not a product.

A product becomes concrete only when it has:
1. immutable product ID;
2. actual artifact;
3. artifact path or explicit delivery route;
4. provenance;
5. QC state;
6. publication/dispatch state;
7. verification state where applicable.
