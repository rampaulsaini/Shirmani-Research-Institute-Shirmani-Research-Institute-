# Continuous Improvement Playbook

### Loop
Observe → identify bottleneck → change one mechanism → produce → measure → retain/revert.

### Production questions
- What output is missing?
- What module is empty?
- Which repeated task can be automated?
- Which product family can be expanded?
- Which customer-facing page is incomplete?

## Rule
Every improvement cycle should increase usable output, reduce friction, or improve quality.
