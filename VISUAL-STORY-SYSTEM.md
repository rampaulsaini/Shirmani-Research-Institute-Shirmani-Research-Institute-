# ꙰ SHIRMANI VISUAL STORY SYSTEM

## Objective
A complete traceable system for expressing the user's framework — निष्पक्ष समझ, शमीकरण, यथार्थ सिद्धांत, उपलब्धि यथार्थ युग, शिरोमणि स्वरूप, हृदय दृष्टिकोण and related vocabulary — through photographs, illustrations, films, animation, cartoons, diagrams and interactive experiences.

## Media pipeline
IDEA → SOURCE/SCRIPT → CONCEPT → CHARACTER/OBJECT DESIGN → STORYBOARD → SHOT LIST → VISUAL ASSET → MOTION/ANIMATION → VOICE/AUDIO → SUBTITLE → EDIT → QC → PROVENANCE → RELEASE → ARCHIVE

## Production formats
**Photography:** portrait projects, conceptual photography, documentary-style records, research/artefact photography, exhibition galleries.

**Illustration:** diagrams, conceptual art, educational illustrations, symbolic scenes, posters and infographics.

**Film:** short films, documentary-style explainers, podcast video, research presentations and long-form projects.

**Animation:** 2D motion graphics, 2D character animation, 3D scenes, conceptual visualization, kinetic typography and explainers.

**Cartoon/visual narrative:** comic panels, character-led explanations, short cartoon episodes, visual parables and educational sequences.

**Interactive:** timeline experiences, concept maps, interactive galleries, scroll-based stories and explorable knowledge scenes.

## Visual asset registry
Each asset records asset ID, project ID, media type, source/reference IDs, creation method, creator/tool attribution where applicable, version, date, license/rights status, derivative-of relationship and QC status.

## Storyboard record
Each scene records scene ID, narrative purpose, exact script/text, visual description, characters/objects, setting, camera/framing, movement, sound/voice, transition, source references and visual-interpretation notes.

## Integrity rule
A visual depiction of a philosophical idea is an artistic or explanatory representation unless independently supported evidence establishes otherwise. That distinction remains in metadata and publication.

## Personal-photo workflow
When an actual personal photograph is used, preserve the original as the source asset and keep edits/AI transformations as separate derivative versions. Never overwrite the source image.

## Release families
PHOTO, POSTER, DIAGRAM, INFOGRAPHIC, SHORT-FILM, DOCUMENTARY, PODCAST-VIDEO, 2D-ANIMATION, 3D-ANIMATION, CARTOON, COMIC, INTERACTIVE-EXPERIENCE.
