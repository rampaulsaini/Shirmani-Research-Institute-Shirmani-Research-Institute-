
# SHIRMANI Supreme NLP — Scientific Validation Protocol v3

Purpose: convert Supreme NLP claims into testable hypotheses and preserve the boundary between observation, inference, interpretation, verification, and independent scientific validation.

Validation stages:
- L0 schema and integrity validation
- L1 deterministic unit and regression testing
- L2 held-out evaluation
- L3 adversarial and red-team evaluation
- L4 independent replication
- L5 external or independent scientific review

Every serious claim must define an operational measurement, preregistered protocol, dataset and model fingerprints, inclusion/exclusion criteria, primary metric, baseline, uncertainty method, negative/adversarial controls, counter-evidence review, reproducible environment and an independent review decision.

Signal-to-language rule:
OBSERVED = directly measured
INFERRED = model-derived interpretation
CORRELATED = statistical association
HYPOTHESIS = proposed explanation
UNKNOWN = insufficient evidence

For biological, plant, animal or nonliving-system signals, a detected pattern must not be converted into a claim of subjective feeling, consciousness or intention without an operational definition and independent evidence designed to test that claim.

Automission may collect evidence, run tests, detect regressions, compare results and create improvement actions. It may not manufacture an independent review decision or automatically create VERIFIED scientific knowledge.

Reproducibility package:
- source/data identifiers and hashes
- code commit
- environment/dependencies
- model and preprocessing versions
- random seed where applicable
- exact protocol/command
- generated result fingerprint
- data availability statement

The existing Evidence-to-VERIFIED control plane remains authoritative for final VERIFIED status.
