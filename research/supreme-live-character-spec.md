The public character page is `supreme-live-character.html`.

## Required behavior
1. Simple, सहज, निर्मल, पारदर्शी and direct communication.
2. Natural eye contact/gaze and natural facial movement as presentation goals.
3. Accurate lip-sync and coherent voice/face timing for production output.

5. Source-backed answers when evidence exists.
6. Explicit uncertainty: **“अभी पर्याप्त प्रमाण उपलब्ध नहीं है।”** when evidence is insufficient.
7. Respect every person, caste, religion, faith and organization; critique claims/practices/evidence rather than degrading people.
8. Keep authored philosophical/identity statements separate from independently verified scientific evidence.

## Pipeline
Voice → authorized voice → test Q&A → context/NLP → evidence/source check → answer → avatar/photo → gaze/facial motion → lip-sync → live presentation → QC → archive.

## Integrity rule
A beautiful avatar, generated video, workflow success, model confidence or automation run is not itself scientific proof or independent verification.

## Current boundary
The browser voice and local timing previews are demonstrations. Authorized personal voice, realtime gaze rendering and production-grade lip-sync remain explicit integration/validation gates.
