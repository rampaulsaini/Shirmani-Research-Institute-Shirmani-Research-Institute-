काम का क्रम — बिना दोहराव के completion gates

01 · Discover

Repository, existing tools, pages और materials की सूची; कुछ भी चुपचाप delete नहीं।

02 · Build

एक चुने हुए काम का वास्तविक output, source links और version record।

03 · Test

Acceptance checks, defects, test date और evidence; बिना test के “complete” नहीं।

04 · Publish

Public page, demo, guide और enquiry path; deployment और बिक्री अलग-अलग मापें।

यह क्रम कार्य-नीति है, अपने-आप चलने वाला background agent या 24/7 scheduler होने का दावा नहीं। इस page को खुला रखने से GitHub Actions, server jobs या external provider jobs अपने-आप शुरू नहीं होते।

विश्वसनीयता और गुणवत्ता के माप

  • Cycle completion % = completed cycles ÷ started cycles × 100; उसी अवधि के logs और स्पष्ट retry नियम होने पर।
  • Acceptance pass % = passed checks ÷ executed checks × 100; test suite/version और sample size साथ दिखें।
  • Evidence coverage % = sampled claims with linked evidence ÷ sampled claims × 100; audit window और exclusions दर्ज हों।
  • Sales conversion % = paid orders ÷ qualified leads × 100; payment-confirmed events से ही।

99.9999% जैसे किसी भी quality, निष्पक्षता, वैज्ञानिक सत्य या uptime प्रतिशत को तभी दिखाया जाए जब पुनरुत्पादित मापन उसे समर्थन दे। दर्शन/लेखक का निजी दृष्टिकोण, परिकल्पना, वैज्ञानिक परिणाम और स्वतंत्र रूप से दोहराया गया प्रमाण अलग-अलग श्रेणियाँ हैं।
