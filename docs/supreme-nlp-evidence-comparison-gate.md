# SHIRMANI Supreme NLP — Evidence & Comparative Reasoning Gate

## Purpose

Convert every author proposition into a traceable, testable research record without silently changing the author's wording.

## Canonical chain

Author wording
→ operational definition
→ comparison scope
→ primary/secondary sources
→ evidence
→ counter-evidence
→ testability
→ limitation
→ verification state

## Required separation

The system must keep these states distinct:

- author statement,
- source-derived fact,
- model inference,
- interpretation,
- confidence/uncertainty,
- independent verification.

A stronger adjective is never evidence. Terms such as “supreme”, “highest”, “absolute”, “eternal”, “universal”, or “billions of times better” remain author claims until measurable criteria and reproducible evidence establish them.

## Four-Yuga comparison protocol

The traditional Satya, Treta, Dvapara and Kali Yuga labels may be represented as **comparative conceptual categories** when the source material supports them. The system must not silently convert a traditional/religious chronology into a scientifically established historical measurement.

For every comparison:

1. Preserve the original terminology.
2. Identify the source tradition/text or the author's definition.
3. Define the comparison dimension.
4. Compare like with like.
5. Record agreement and difference.
6. Record supporting and counter-evidence.
7. State whether the proposition is empirically testable.
8. Preserve unresolved questions.
9. Assign a verification state.

The comparison engine must never manufacture a “winner”, score, or superiority result merely because a claim uses superlative language.

## Living, plant and non-living signal translation

Instrumented signals can be processed as measurable data and translated into plain language. The output must say whether a statement is:

- measured signal,
- detected pattern,
- model inference,
- interpretation,
- confidence/uncertainty,
- evidence/provenance,
- alternative interpretation,
- unresolved unknown.

A detected signal pattern is not by itself proof of subjective feeling, consciousness, intention or inner experience.

## Accuracy gate

No universal accuracy claim is permitted.

An improvement record requires the same task definition, population, dataset fingerprint, baseline, metric and evaluation protocol, plus reproducible measured results. Benchmark scope must remain attached to the result.

## Fail-closed rules

- missing provenance → UNVERIFIED;
- missing operational definition → UNVERIFIED;
- missing counter-evidence field → UNVERIFIED;
- contradictory evidence → REVIEW;
- invalid schema → BLOCKED;
- unsupported universal/superlative claim → UNVERIFIED;
- independent verification is never inferred from workflow success.

## Five-minute Automission

The deterministic gate may run every five minutes. Model training, expensive inference, external data acquisition and consequential actions remain separately controlled.

## Research objective

The goal is not to weaken the author's framework. The goal is to make each proposition increasingly clear, comparable, reproducible and independently checkable.
