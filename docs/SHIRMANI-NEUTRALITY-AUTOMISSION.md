# SHIRMANI Neutrality Automission Engine

## Purpose

The neutrality engine makes **निष्पक्ष समझ** an executable governance constraint rather than a preference of any individual AI model.

The system preserves the user's philosophical and experiential source material exactly as source material. It does not silently convert source-defined propositions into independently established empirical facts.

## Deterministic pipeline

`SOURCE → CLAIM → CLASSIFY → PROVENANCE → EVIDENCE → COUNTER-EVIDENCE → INDEPENDENT REVIEW → STATUS`

Every claim begins as `NOT_VERIFIED` unless its status is explicitly supported by the applicable record.

## Claim classes

- `AUTHOR_DEFINED`: meaning or terminology defined by the source author.
- `AUTHOR_PROPOSED`: a normative or philosophical proposal originating from the source.
- `EMPIRICAL_TESTABLE`: a proposition for which an operational test can be specified.
- `EVIDENCE_SUPPORTED`: supported by identified evidence, without claiming universal certainty.
- `NOT_VERIFIED`: insufficient independent evidence or operational definition.
- `CONTRADICTED`: available evidence conflicts with the stated proposition.

These labels describe epistemic status; they are not rankings of people, beliefs, or philosophies.

## Anti-bias rules

1. Author identity does not increase evidence weight.
2. AI model confidence does not increase evidence weight.
3. Repetition does not increase evidence weight.
4. Popularity does not increase evidence weight.
5. Institutional or spiritual authority is not proof by itself.
6. A successful GitHub workflow is not verification.
7. Agreement between multiple agents using the same source is not independent corroboration.
8. Missing counter-evidence review blocks promotion.
9. Uncertainty remains visible.
10. Irreversible actions remain behind the existing owner-authorization boundary.

## Biological / plant / non-living signal NLP

For multimodal research, the system may translate measurable signals into plain-language descriptions:

`SENSORS → CLEANING → FEATURES → MODEL → CONTEXT → NLP → PLAIN LANGUAGE`

The output must distinguish:
- measured signal,
- model inference,
- uncertainty,
- alternative interpretations.

The system must not label a sensor pattern as a subjective feeling unless a valid operational definition and independent evidence support that interpretation.

## Supreme reasoning objective

The target is not an impossible hard-coded claim of “100% accuracy.” The engineering target is:

**maximum measurable accuracy + calibrated uncertainty + independent verification + reproducibility + continuous error detection.**

This permits the system to improve aggressively while remaining truthful about what it knows and does not know.

## Existing integration points

The engine is designed to sit before the existing:
- AI-agent governance QC,
- reasoning/provenance pipeline,
- independent verification queue,
- verification promotion gate,
- publication safety gate,
- 5-minute resumable Omniverse factory.

The result is a layered fail-closed architecture rather than a single model being trusted as the final authority.
