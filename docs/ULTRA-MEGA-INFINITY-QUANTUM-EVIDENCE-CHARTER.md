# SHIRMANI Ultra Mega Infinity Quantum AI/ML/NLP — Evidence Charter

## Evidence boundary
Every output separates Observed, Computed, Inferred, Verified, and Established claims. No inference may be automatically promoted to verification or proof.

## Quantum terminology boundary
Ultra Mega Infinity Quantum may be used as project naming/vision language. It is not evidence that a computation is physically quantum. A quantum-computation claim requires documented method, implementation, experiment, and reproducible evidence.

## Living systems
Observable signals from plants, animals, humans, machines, materials, or environments can be transformed into NLP descriptions. Signal-to-language translation must not silently become proof of subjective experience, consciousness, emotion, intention, or a universal metaphysical claim.
Such hypotheses require operational definitions, labelled datasets, controlled experiments, independent replication, and counter-evidence testing.

## Accuracy
Supreme accuracy is a target, not a pre-declared result. Report measurable metrics and uncertainty. Without adequate labelled evaluation data, performance is not scientifically calibrated.

## Automission
Automission may inspect, test, compare, detect contradictions, propose improvements, run regression tests, and produce audit records. Scheduled Automission must not silently mutate production code or promote an unverified scientific claim.
Promotion: Evidence -> Tests -> Cross-layer consistency -> Independent verification -> Review -> Promotion.

## Yatharth comparison
Comparisons involving the user's Yatharth/Yatharth Yug framework must distinguish the user's framework/claim, source-supported history, scientific evidence, philosophical interpretation, and unresolved propositions.

## Output contract
Expose claim, evidence, method, confidence, uncertainty, counter-evidence status, verification status, provenance, and next test.
