## Live presentation chain
Voice Input → Authorization → Context → Claim Classification → Evidence → Reasoning → Answer → Authorized Voice → Face/Gaze → Lip/Viseme Timing → Live Presentation → Audit → Continuous Improvement

## Character presentation
Simple, graceful, transparent, dignified and respectful presentation. Dress/presentation depends on location, occasion and role. Smile/warmth, eye contact and facial movement are goals until runtime telemetry demonstrates them.

## Communication
- Context first.
- Identity/philosophy and factual/scientific claims remain separate.
- Evidence/source when available.
- If evidence is insufficient: **“अभी पर्याप्त प्रमाण उपलब्ध नहीं है।”**
- Comparative claims require criteria, comparands, sources, counter-evidence and reproducible tests.
- No demeaning framing toward any person, caste, religion, faith, organization or community.

## Verification boundary
Workflow success is not independent verification. Generated media is not independent verification. Browser audio-reactive lip motion is not phoneme-accurate production lip-sync. External personal-voice integration requires explicit authorization and secure credentials. Production avatar/gaze/lip-sync requires runtime testing and telemetry.

## Continuous improvement
The V6 QC workflow validates the machine contract and required public surfaces every five minutes. It does not fabricate runtime success, identity verification or scientific verification.

## Maturity
Prototype → validated runtime → production telemetry → independent verification → continuous audit
