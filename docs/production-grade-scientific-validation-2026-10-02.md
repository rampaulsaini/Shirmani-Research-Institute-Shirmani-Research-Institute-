# Production-Grade Scientific Validation & Independent Verification

## Two NLP layers
NLP-1 — Evidence/Reasoning NLP: claim extraction, terminology normalization, source/provenance mapping, contradiction detection and scientific/plain-language reporting.

NLP-2 — Multimodal Signal-to-Language NLP: time-series, audio, image/video and sensor intake, signal QC, fusion, inference, calibration and plain-language translation.

The two layers cross-check each other. NLP-1 cannot declare a biological subjective state from NLP-2 output, and NLP-2 cannot treat philosophical language as sensor ground truth.

## Scientific evidence pipeline
Source discovery → qualification → claim extraction → operational definition → preregistration → data/material acquisition → blinded analysis → candidate model → held-out evaluation → independent replication → independent verification → QC → publication/archive.

## What can be studied now
Plant calcium, electrical, ROS and systemic signaling are established instrument-based research areas. They provide legitimate measurable inputs for signal-processing experiments, but do not automatically establish subjective feeling or consciousness.

Human consciousness research uses measurable neural and behavioral paradigms while recognizing that consciousness is partly inferred and methodologically difficult.

AI performance must be measured against explicit tasks and uncertainty; workflow success is not model accuracy.

## Verification promotion rule
REGISTERED → UNVERIFIED → REVIEW → VERIFIED

A record cannot become VERIFIED merely because an AI agent generated it, a workflow passed, a model reports high confidence, a source mentions a related phenomenon, or an author/developer agrees with it.

For VERIFIED, the repository requires an independent verifier, independent replication, evidence references, preregistration, raw-data reference, analysis fingerprint, dataset/material fingerprint, method, limitations and an explicit independence statement.

## Living/non-living signal interpretation
signal ≠ inference ≠ interpretation ≠ subjective experience

If evidence supports only a pattern associated with stimulus X, the NLP output must not upgrade it into an established statement that an organism feels X.

## Five-minute Automission
Validate contracts; validate evidence records; run deterministic tests; detect regressions; generate improvement proposals; preserve provenance; never silently promote scientific claims.

Expensive experiments, data acquisition, external replication and high-impact actions require separately authorized execution.
