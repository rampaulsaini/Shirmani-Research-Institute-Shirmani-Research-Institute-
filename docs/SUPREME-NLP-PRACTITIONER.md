# SHIRMANI HEART-VIEW SUPREME NLP PRACTITIONER

## Purpose
This layer extends the Supreme NLP + Automission foundation with a deterministic,
multimodal, evidence-preserving practitioner control plane.

## Pipeline
observe -> normalize -> quality -> robust statistics -> multimodal fusion ->
uncertainty -> semantic intent -> language explanation -> audit

## Improvements
- Mean, median, MAD and variability for robust signal summaries.
- Multimodal corroboration and independent-source counting.
- Outlier awareness instead of hiding disagreement.
- Confidence decomposition using quality, agreement, diversity and replication.
- Hindi/Punjabi/English/Japanese/Chinese language detection baseline.
- Intent routing for measurement, causal and experience-interpretation requests.
- Explicit fail-closed governance.

## Biological and physical signals
Measured signals can be translated into simple language, but a signal pattern
is not treated as proof of subjective feeling. Stronger claims require an
operational definition, labelled data, controlled experiments, calibration,
independent replication and domain review.

## Accuracy path
Later ML/NLP models can replace individual components while preserving the
same evidence and governance contract. Performance must be measured with held-
out data, calibration, regression tests, counter-examples and independent
verification. Absolute accuracy is not claimed without evidence.
