# Supreme AI–ML–NLP–Automission Quality Contract

## Continuous loop
**Observe → Collect → Normalize → Analyze → Reason → Execute → Test → Verify → Audit → Learn → Improve**

No stage may silently promote an inference into an observed fact.

## Multimodal → NLP
The platform can accept text, speech, image/video and measurable sensor/environmental signals and translate patterns into simple language.

Outputs distinguish:
- **OBSERVED** — directly measured signal.
- **INFERRED** — model-derived interpretation.
- **HYPOTHESIS** — explanation requiring testing.
- **UNRESOLVED** — insufficient evidence.

For biological or non-biological systems, the default language must describe measured signals, possible interpretation, confidence and uncertainty rather than asserting subjective experience as established fact.

## Accuracy contract
The system does not manufacture “100% accuracy”. Every model result carries provenance, confidence, uncertainty, pipeline version and verification state.

Independent verification remains separate from automated QC.

## Agent contract
**Intake → Evidence → ML/NLP → Reasoning → Production → Verification → Security → Publication → Continuity**

Irreversible actions remain owner-authorized. High-impact publication or verification promotion requires independent evidence.

## Repository federation
The central institute may coordinate the repository network, but inventory membership does not imply operational status. **CONNECTED** requires actual dispatch/receipt evidence; **VERIFIED** requires independent verification evidence.

## Measurable improvement
Track precision/recall, reproducibility, latency, failure recovery, provenance coverage, verification coverage, security posture and user-visible clarity.
