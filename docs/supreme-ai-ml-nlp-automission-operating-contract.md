# Supreme AI–ML–NLP–Automission Operating Contract

## Purpose

This contract operationalizes the canonical Supreme AI–ML–NLP–Automission graph as an evidence-first, fail-closed, continuously audited research system.

## Core pipeline

Observe → Collect → Normalize → Analyze → Reason → Execute → Test → Verify → Audit → Learn → Improve

No stage may silently skip provenance, uncertainty, validation, or safety gates.

## Evidence states

- OBSERVED — directly measured or recorded input.
- DERIVED — deterministic transformation of an observed input.
- INFERRED — model-generated interpretation.
- EXPLAINED — human-readable NLP rendering of an inference.
- VERIFIED — independently checked against an explicit verification procedure.
- PUBLISHED — approved for public presentation.
- ARCHIVED — immutable historical record.

These states are not interchangeable. In particular, INFERRED ≠ VERIFIED and VERIFIED ≠ scientific proof of a subjective experience.

## Multimodal / biological / environmental signal rule

Signals from humans, animals, plants, environments, machines, or non-living systems may be processed when they are measurable and lawfully collected.

The system must preserve five distinct fields:

1. measured signal;
2. model inference;
3. interpretation;
4. confidence/calibration;
5. unresolved uncertainty.

The NLP layer may translate patterns into simple language, but it must not convert a model inference into a factual claim of consciousness, emotion, pain, intention, or subjective experience without independent evidence supporting that claim.

## Agent contracts

### Planner Agent
Defines the task, expected outputs, constraints, and verification plan.

### Research Agent
Collects sources and produces traceable research artifacts.

### Evidence Agent
Links claims to observations, sources, tests, counter-evidence, and provenance.

### NLP Interpreter Agent
Converts structured findings into clear language while preserving uncertainty.

### Code Agent
Proposes implementation changes and must pass tests before production use.

### Security Agent
Checks secrets, permissions, unsafe execution paths, dependency risks, and injection boundaries.

### Verification Agent
Runs an independent verification procedure that is separate from preparation/QC.

## Fail-closed gates

A release or production modification must stop when any required gate is missing or fails:

- schema validation;
- provenance validation;
- regression tests;
- security checks;
- verification status;
- uncertainty/calibration record;
- required human approval for high-impact actions.

## Accuracy contract

Accuracy is measured, never declared.

Each benchmark should report, where applicable:

- precision;
- recall;
- F1;
- calibration/error;
- false-positive and false-negative rates;
- robustness across languages/domains;
- signal-to-language fidelity;
- reproducibility;
- independent verification rate.

“Fully supreme accuracy” is therefore treated as an engineering target, not a pre-certified numerical fact.

## Five-minute Automission policy

The scheduled supervisor may inspect repository health every five minutes.

Each cycle should:

1. inspect required artifacts;
2. validate machine-readable schemas;
3. detect broken references or missing gates;
4. run available deterministic tests;
5. emit a timestamped audit result;
6. fail closed on critical errors;
7. preserve artifacts for traceability.

Autonomous code changes are not automatically promoted to production. Changes affecting security, external systems, money, identity, legal status, or other high-impact areas require human review.

## Continuous improvement

Improvement proposals must carry:

- baseline version;
- proposed change;
- expected benefit;
- measured result;
- regression result;
- evidence;
- rollback path.

No improvement is accepted solely because an agent claims that it is better.

## Minimum audit record

Every cycle should identify:

- cycle timestamp;
- commit/ref;
- checks performed;
- checks passed;
- checks failed;
- verification status;
- unresolved risks;
- artifact locations.
