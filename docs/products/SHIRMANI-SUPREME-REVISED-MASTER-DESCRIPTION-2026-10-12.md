## Interaction pipeline
**Question/input → speech recognition (if enabled) → context and intent → evidence check → response composition → authorized voice output → face/avatar presentation → lip-sync → live delivery → audit and improvement.**
Each stage must have a real status. A text-only prototype is not a live AI avatar.

## Evidence gate
Use these states where relevant:
- **VERIFIED:** the stated test or independent verification is complete and evidence is available.
- **SOURCE-BASED:** a source is cited but independent verification is incomplete.
- **PHILOSOPHICAL / IDENTITY:** personal philosophy, interpretation or self-description.
- **INSUFFICIENT EVIDENCE:** say, **“अभी पर्याप्त प्रमाण उपलब्ध नहीं है।”**

Do not present philosophical or spiritual statements as independently established scientific facts. Research papers must distinguish question, hypothesis, method, sources, results, uncertainty, limitations and conclusions. Never invent equations, citations, statistics or test results.

## Acceptance tests
Before calling the character production-ready, retain evidence for:
- Context understanding and plain-language/specialist explanation tests.
- Source citation and insufficient-evidence behavior.
- Respectful communication regression tests.
- Original-photo provenance and authorized-voice checks.
- Speech input/output, facial movement, gaze and lip-sync tests if those integrations exist.
- Measured audio/video synchronization and end-to-end latency if connected.
- Product-specific QR scan and destination.
- Actual screenshot, MP4 playback and usage-guide review.
- Accessibility/readability on mobile and desktop.
- Regression tests after updates.

A failed critical gate blocks VERIFIED / production-ready status.
