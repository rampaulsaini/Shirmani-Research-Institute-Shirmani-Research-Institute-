- **Purpose:** Prepare a character/presentation brief, evidence rules, and measurable rehearsal/testing checklist for respectful, clear communication.
- **Inputs:** User-entered public identity, presentation context, language/style preferences, and evidence/source notes.
- **Outputs:** Browser-local brief and checklist, with copy/save-to-text controls.
- **Privacy:** This page's brief generation is client-side; it does not submit the brief to a server.
- **Limitations:** No connected AI model, live web research, independent source verification, voice cloning, avatar generation, lip-sync, MP4 recording, payment, email sending, or automated sales.
- **Demo media:** Product page is an interactive browser demo; a separately recorded MP4 is not yet attached.
- **VIP screenshot:** Not yet captured from a running session. The SVG cover is a product visual, not a screenshot.
- **QR:** QR destination should resolve to the public demo page. A first-party QR image is not yet committed.
- **QC release criteria:** Test all inputs, copy/export, mobile layout, evidence caveat, source notes, and ensure philosophical/identity statements are not presented as independently verified scientific claims.
- **Feedback loop:** Link reproducible user feedback to a version and documented fix. Do not invent reviews or ratings.

## Evidence states
- Philosophical / identity statement
- Source-based; independent verification pending
- User-marked verified (user declaration only, not independently verified by this tool)
- Insufficient evidence
