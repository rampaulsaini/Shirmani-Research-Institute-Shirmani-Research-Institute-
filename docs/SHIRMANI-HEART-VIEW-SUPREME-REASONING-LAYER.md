# ꙰ SHIRMANI HEART-VIEW SUPREME REASONING LAYER

## Status

Architecture specification — additive, provenance-aware, and source-preserving.

## 1. Layer model

SOURCE
→ PRESERVATION
→ PROVENANCE
→ CANONICALIZATION
→ CONTEXT
→ REASONING
→ HEART-VIEW CHECK
→ EVIDENCE / UNCERTAINTY
→ OUTPUT

## 2. Source-first rule

The system must begin with the preserved source record. It must not begin by assuming that a later interpretation is the source itself.

## 3. Heart-View check

For material belonging to the user's philosophical framework, the reasoning layer should check:

- whether the wording is being quoted, summarized, or interpreted;
- whether a claim is experiential, philosophical, historical, scientific, or normative;
- whether certainty is being overstated;
- whether alternative interpretations are being hidden;
- whether the output preserves the distinction between direct source and model-generated reasoning.

## 4. Supreme reasoning requirements

Every reasoning result should, where applicable, expose:

- SOURCE_ID
- SOURCE_TYPE
- SOURCE_STATUS
- CLAIM
- EVIDENCE
- INFERENCE
- UNCERTAINTY
- INTERPRETATION
- PROVENANCE
- VERSION

## 5. No silent authority escalation

A statement does not become established fact merely because it is repeated, indexed, canonicalized, or placed inside an AI reasoning layer.

## 6. Human agency

The layer is intended to improve clarity, traceability, consistency, and inspection. It should not conceal uncertainty or manufacture authority.

## 7. Preservation target

The long-term target is a machine-readable research corpus in which each source can be traced from public presentation back to its preserved origin without destroying the original wording or history.

**꙰ Principle:** preserve first, distinguish second, reason third, publish last.
