## 7. Quality Gates

## 8. Self-Improvement Boundary
Agent proposes change → isolated branch → tests → quality controller → security → independent verification → review/approval where consequential → production → monitoring → rollback on regression.

## 9. Human/Living-System/Material Interpretation Boundary
The system may translate measurable signals from humans, animals, plants, materials and environments. A signal is not automatically proof of subjective feeling, consciousness, intention, emotion, soul, or quantum state. Observation, interpretation, hypothesis and established evidence remain separate.

## 10. Supreme Accuracy Target
“Supreme accuracy” is an engineering target, not an unsupported absolute claim.

Measure:
- precision / recall / F1 where applicable
- calibration
- false-positive / false-negative rates
- reproducibility
- robustness
- provenance completeness
- uncertainty quality
- independent verification rate
- regression rate
- latency

## 11. Continuous Evidence Ledger
Every material result: source → timestamp → model/version → input quality → transformation → output → uncertainty → verification → audit trail.

## 12. Protection & Stewardship Layer
Integrated understanding of human, living-system, environmental and material signals → risk detection → evidence-based interpretation → responsible protection/stewardship actions → monitoring → feedback.
