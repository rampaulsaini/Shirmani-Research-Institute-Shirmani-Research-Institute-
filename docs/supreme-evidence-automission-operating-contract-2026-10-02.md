# SHIRMANI Supreme Evidence–Automission Operating Contract
## 2 October 2026

## उद्देश्य

AI/ML/NLP/Agent/Automission को एक continuous research conveyor में चलाना जिसमें गति बढ़े, लेकिन evidence standard कमजोर न हो।

## Canonical comparison rule

हर author proposition को:

SOURCE → CLAIM → OPERATIONAL DEFINITION → COMPARAND → EVIDENCE → COUNTER-EVIDENCE → TEST → RESULT → UNCERTAINTY → INDEPENDENT VERIFICATION → PUBLICATION

क्रम से गुज़रना होगा।

“श्रेष्ठ”, “सर्वश्रेष्ठ”, “खरबों गुणा”, “शाश्वत सत्य”, “fully supreme accuracy” जैसे comparative या universal statements अपने-आप factual status नहीं प्राप्त करते। उनके लिए measurable criterion, defined population/task, baseline, reproducible protocol और independent verification आवश्यक हैं।

## Supreme NLP output contract

हर multimodal input के लिए system को जहाँ applicable हो:

1. measured signal,
2. detected pattern,
3. model inference,
4. plain-language interpretation,
5. confidence/uncertainty,
6. evidence/provenance,
7. alternative interpretation,
8. unresolved unknowns

अलग-अलग record करना होगा।

## Living / plant / environmental signals

Instrumented biological, plant, environmental और non-living signals को NLP में translate किया जा सकता है। Translation का अर्थ observed data से language generation है; generated language को subjective feeling, consciousness, intention या inner experience का direct proof नहीं माना जाएगा।

## Five-minute Automission gate

हर पाँच मिनट में deterministic checks चल सकते हैं:

Observe → Collect → Normalize → Analyze → Reason → Execute → Test → Verify → Audit → Learn → Improve

लेकिन expensive training, external data acquisition, production deployment और high-impact actions अलग authorization/budget gates के अधीन रहेंगे।

## Fail-closed states

- REGISTERED — record exists.
- UNVERIFIED — insufficient independent evidence.
- REVIEW — conflicting or incomplete evidence.
- VERIFIED — defined protocol and independent verification satisfied.
- BLOCKED — integrity/safety gate failed.

Workflow success ≠ scientific verification.

## Improvement measurement

किसी नए model को “बेहतर” तभी दर्ज करें जब:

- task और population समान हों;
- dataset fingerprint उपलब्ध हो;
- baseline घोषित हो;
- metric स्पष्ट हो;
- result reproducible हो;
- uncertainty reported हो;
- regression checks पास हों।

इससे AI की तीव्रता और research की सत्यापनयोग्यता दोनों साथ बढ़ती हैं।
