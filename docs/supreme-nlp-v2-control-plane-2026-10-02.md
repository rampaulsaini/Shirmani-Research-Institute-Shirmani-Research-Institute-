# SHIRMANI Supreme NLP v2 — Control-Plane Hardening

## What this layer adds
1. deterministic multilingual baseline cases;
2. abstention probes for negation and conflicting lexical evidence;
3. bounded confidence/domain checks;
4. immutable evidence state: benchmark results remain UNVERIFIED;
5. Python compilation checks;
6. existing end-to-end NLP tests;
7. existing unified fail-closed gate;
8. existing Total AI/ML/NLP Automission orchestrator;
9. generated evidence reports uploaded as workflow artifacts.

## Five-minute Automission boundary
The scheduled workflow runs every five minutes, but it is read-only with respect to repository contents. It can observe, test, benchmark, audit and report. It does not push commits, merge pull requests, or mutate production code.

## Signal-to-language boundary
For living organisms, plants, environmental systems and non-living sources, the system may translate measurable signals into plain language when data are available. The output must distinguish measured signal, model inference, interpretation, confidence and unresolved uncertainty.

A signal-derived explanation is not automatically evidence of subjective feeling, consciousness, intention or inner experience.

## Accuracy
Accuracy is measured against named evaluation fixtures and task-specific metrics. No workflow status is treated as proof of model accuracy, and no universal or perfect-accuracy claim is generated by this layer.

## Promotion
OBSERVE -> TEST -> BENCHMARK -> GATE -> VERIFY -> QC -> PUBLISH

Until independent verification exists, scientific/model claims remain UNVERIFIED and promotion remains blocked.
