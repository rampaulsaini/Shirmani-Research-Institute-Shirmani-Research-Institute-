# SHIRMANI Live Presentation System

Pipeline:

voice input -> authorized voice integration -> context/Q&A -> evidence gate -> response -> voice output -> photo presentation -> lip-sync -> live presentation

## Quality requirements

- सरल, सहज, निर्मल, पारदर्शी communication
- natural eye-contact/gaze
- natural facial movement
- accurate lip-sync
- voice/face timing coherence
- context-aware Q&A
- source-linked answers when evidence exists
- clear uncertainty when evidence is insufficient
- no denigration of people, castes, religions, faiths, organizations, or groups
- philosophical/identity statements separated from independently verified scientific claims

## Evidence gate

question -> context -> evidence lookup -> claim classification -> answer -> citation/uncertainty -> presentation

When evidence is inadequate:

"अभी पर्याप्त प्रमाण उपलब्ध नहीं है"

## Product integration

Connect the existing product factory to:

visual -> QR -> passport -> demo -> usage guide -> review/rating -> quality improvement

Target scale:
- 5,000 concrete products
- 150,000-record sharded catalogue
- official-link mapping for Companies / Government / Science / Organisations
- lawful outreach only through a real authorized outbound channel

## Truthfulness gate

The system must not claim a live provider, external contact, scientific verification, or completed delivery unless the corresponding real evidence exists.

## Provider boundary

Actual voice synthesis and lip-sync require a real authorized provider or runtime. The repository stores configuration and audit logic, not provider secrets.

## Definition of done

authorized source -> provider configured -> evidence gate -> voice output -> lip-sync output -> timing QA -> live presentation
