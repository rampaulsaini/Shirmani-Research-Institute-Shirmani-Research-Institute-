# निष्पक्ष समझ निरीक्षण — Framework v0.1

## उद्देश्य
यह framework व्यक्ति को स्पष्ट उद्देश्य, consent, claims, sources, evidence, analysis और human review के माध्यम से structured inspection देता है। AI संरचना, भाषा-सहायता, consistency checks और evidence routing में सहायता करता है; वह मानव गरिमा, कानूनी अधिकार, नियुक्ति या सार्वजनिक पद की अंतिम पात्रता का निर्णय नहीं करता।

## Purpose gate
Session शुरू होने से पहले purpose चुनना अनिवार्य है: human_self_understanding, education, employment, professional_role, public_role_criteria, self_reflection.

## Evidence states
REGISTERED → EVIDENCE_PENDING → SUPPORTED / CONTESTED / NOT_VERIFIED → REVIEW_REQUIRED → ARCHIVED.

AI_OUTPUT ≠ EVIDENCE
QC_PASS ≠ TRUTH
SUPPORTED ≠ LEGAL_ELIGIBILITY
VERIFIED ≠ APPOINTMENT

## Multi-angle analysis
शब्दार्थ/context, समय-संदर्भ, provenance, प्रत्यक्ष/अप्रत्यक्ष evidence, fact/interpretation separation, internal consistency, corroboration, counter-evidence, uncertainty और reproducibility अलग-अलग record हों।

## Optional sensing
Finger-vein, iris/eye-quality, voice आदि केवल explicit consent, purpose limitation, lawful processing और secure infrastructure के अंतर्गत optional modalities हैं। Raw biometric material public ledger/certificate में नहीं रखा जाएगा। Sensing failure को व्यक्ति के विरुद्ध स्वतः निर्णय नहीं बनाया जाएगा।

## NLP boundary
NLP literal meaning, ambiguity, negation, temporal references, quotation, attribution और contradiction candidates निकाल सकता है। यह lie detection, psychological diagnosis या hidden intent की certainty का दावा नहीं करेगा।

## Public-role boundary
PM, CM, मंत्री, न्यायाधीश या अन्य सार्वजनिक पद के लिए app केवल लागू और documented criteria को map कर सकता है। कानूनी eligibility, appointment या political decision अधिकृत मानव/संस्थागत प्रक्रिया के अधीन रहेगा।

## Certificate
Certificate में purpose, claims, evidence references, method/version, AI assistance disclosure, human review, verification state, limitations, issue/expiry और correction/revocation mechanism होना चाहिए।

## Scale
Privacy by default, encryption, append-only audit trail, deterministic schemas, idempotent workflows, rate limiting, localization, accessibility, human escalation, retention/deletion controls और disaster recovery को baseline माना जाए।

## Automation
intake → purpose-gate → consent-gate → evidence-normalize → claim-map → source-check → contradiction-check → privacy-check → QC → human-review-queue → certificate-draft → authorized-release → archive.

## Livelihood
Verified Skills → Work Opportunities → Demonstrated Work → Delivery Evidence → Verified Contribution → Authorized Settlement. Inspection result को guaranteed income नहीं माना जाएगा।

## Integrity rule
जहाँ evidence नहीं है वहाँ system value नहीं गढ़ेगा। जहाँ disagreement है वहाँ disagreement record करेगा। जहाँ human/legal decision आवश्यक है वहाँ automation उसे replace नहीं करेगा।
