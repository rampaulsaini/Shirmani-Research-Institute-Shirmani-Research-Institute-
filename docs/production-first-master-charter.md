# ꙰ SHIRMANI Production-First Master Charter

Production is the mission. QC is the gate. Showroom is the public presentation and sale layer. Verification is downstream.

## Four stages

1. INSTITUTE — discovery of repository modules, research opportunities, product ideas and AI/ML/NLP work lanes.
2. FACTORY — every selected work unit becomes a concrete output, product asset, executable module or reusable production artifact. A name, catalog row or workflow run alone is never treated as a product.
3. QC — deterministic checks for structure, asset, metadata, QR payload, QC code, Gate No., price/offer, guarantee and packing. Dispatch defaults to NO.
4. SHOWROOM / SALE — public presentation of product name, category, description, price, offer, guarantee, premium packing, QR passport, QC code, Gate No. and dispatch state. Showroom entry fee is separate from product price.

## Multi-layer Automission

Every 5-minute cycle prioritizes: DISCOVER → QUEUE → PRODUCE → MATERIALIZE → PACKAGE → PUBLISH → QC → SHOWROOM → MEASURE → NEXT WORK.

A stalled lane should not suppress other safe independent production lanes.

## Product truth states

IDENTITY → PRODUCTION-CANDIDATE → PRODUCED → READY_FOR_QC → QC_PASS_READY_FOR_DISPATCH → DISPATCH_NO → DISPATCH_YES.

A workflow run is not itself a product.

## Continuous operation

Scheduled GitHub Actions are designed to continue without an open chat, subject to GitHub Actions availability, permissions, quotas and workflow health.

## Quantum boundary

“Ultra Mega Infinity Quantum” may describe the orchestration architecture. Real quantum-hardware execution is claimed only when a real quantum backend is configured and available.

## Success metrics

Primary: new concrete production outputs per cycle. Secondary: active production modules per cycle. Third: publicly published products. QC and downstream verification are later quality/release metrics.

## Current target

The current factory architecture is configured for 1,016 concrete product identities, 25 executable family engines/modules and product-specific production assets. Future Automission cycles should expand these into increasingly useful and diverse products.
