# AI / ML / NLP / Automission Governance Contract

## Architecture
L1 Intake → L2 NLP understanding → L3 classification → L4 evidence/recommendation → L5 policy/safety checks → L6 action proposal → L7 execution where permitted → L8 audit → L9 feedback/learning.

## Autonomous actions allowed by design
Routine indexing, translation, content organization, workflow scheduling, health checks, quality checks, research packet preparation and reversible low-risk operations may be automated.

## Human-control gates
Human review and appeal remain mandatory for high-impact decisions such as account termination, significant financial actions, disputes, justice outcomes, access to essential services and independent scientific verification.

## Fail-closed rules
- missing evidence never becomes VERIFIED
- automation success never becomes scientific verification
- model confidence never becomes truth
- popularity never becomes correctness
- a generated recommendation never becomes a binding public decision without the required governance gate
- failures are logged and recoverable

## Learning loop
Observe → evaluate → test → review → deploy → monitor → rollback when needed.

## Security
Secrets must remain outside public content and logs. Least privilege, signed/reviewed changes, audit trails, rate limits, abuse detection, privacy controls and recovery procedures are required.
