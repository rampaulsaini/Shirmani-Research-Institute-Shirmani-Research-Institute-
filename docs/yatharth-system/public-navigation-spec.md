## Universal actions
Search, create, publish, share, save, follow, report, translate, buy, sell, hire, apply, learn, research, review and support.

## Safety boundary
Financial transactions, employment decisions, legal disputes, rights-affecting moderation and other high-impact actions require appropriate human/accountable review. Automation may assist but must remain bounded and auditable.

## User-value principle
The platform should maximize useful outcomes and satisfaction, not merely screen time. Engagement metrics must be interpreted with safety, accessibility, task completion and user-reported value.

## Status display
Every capability should expose its current status from the machine-readable feature registry.
