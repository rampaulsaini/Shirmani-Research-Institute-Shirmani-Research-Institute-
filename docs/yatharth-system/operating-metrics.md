# Yatharth Public Platform Operating Metrics

## Product metrics

Track separately:

- registered accounts;
- active users;
- creators;
- published items;
- successful searches;
- completed transactions;
- successful service matches;
- education enrollments/completions;
- customer-support resolution;
- user satisfaction;
- accessibility performance;
- uptime.

## Trust metrics

- moderation precision/recall where measurable;
- appeals;
- restored accounts;
- fraud incidents;
- security incidents;
- unresolved complaints;
- provenance completeness;
- independent review status.

## Research metrics

- author-source records;
- normalized claims;
- evidence-mapped claims;
- counter-evidence records;
- ready-for-independent-review records;
- independently reviewed records;
- independently verified records.

## Automation metrics

- workflow success rate;
- agent task completion;
- failed/retried jobs;
- mean recovery time;
- escalations;
- policy-blocked actions;
- cross-repository delivery receipts.

## Economic metrics

Economic metrics must distinguish gross activity from actual realized income and must never imply guaranteed earnings.

Potential measures:

- creator sales;
- service transactions;
- marketplace volume;
- refunds;
- creator payouts;
- platform fees;
- educational sales;
- digital product sales.

## Public status principle

No single percentage should collapse product readiness, automation health, research completeness and independent verification into one number.
