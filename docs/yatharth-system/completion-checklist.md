## Completion rule
किसी module को केवल documentation के कारण LIVE नहीं माना जाएगा। LIVE status के लिए implementation, tests, security/privacy controls, monitoring, rollback/appeal और user-facing status आवश्यक हैं।

## Continuity rule
**देखें → समझें → अलग करें → छोटा अगला कदम → करें → परिणाम दर्ज करें → सीखें → सुधारें → दोहराएँ**

संपूर्ण संतुष्टि की निरंतरता का operational अर्थ है: सत्यनिष्ठ निरीक्षण, उपयोगी कार्य, प्रमाण-आधारित सुधार और सुरक्षित अगला कदम।
