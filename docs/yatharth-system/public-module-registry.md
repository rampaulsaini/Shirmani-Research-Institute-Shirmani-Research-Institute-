# Public Module Registry

This registry is the public-facing product map. Internal agents and workflows may implement these modules, but the registry is the source of truth for what the public platform intends to expose.

| Domain | Public modules |
|---|---|
| Identity & Social | Account, profile, feed, posts, comments, messaging, communities, creator pages |
| Knowledge | Yatharth source, articles, books, library, search, multilingual knowledge |
| Research | claims, evidence, counter-evidence, comparisons, research reports, verification dashboard |
| Education | academy, courses, learning paths, skills, assessments, certificates |
| AI | Yatharth AI, AI assistant, AI services, AI/ML/NLP research, agent services |
| Creative | Yatharth AI Music, audio, video, podcast, live, creator studio |
| Commerce | Digital Store, products, subscriptions, licensing, checkout, orders, reviews |
| Work | Freelancing, jobs, services, portfolios, client/provider matching |
| Economy | creator income, service income, research income, economic metrics, proposed Yatharth currency research |
| Justice & Trust | complaints, appeals, dispute support, transparency, provenance, independent review |
| Humanity & Earth | nature, Earth, biodiversity, human welfare, sustainability and protection initiatives |
| Community | discussions, groups, participation, volunteering, partnerships |
| Platform | dashboard, notifications, support, accessibility, privacy, security, governance |

## Account capability

A registered user may, subject to applicable rules and verification requirements, create a profile, publish content, offer services, list eligible digital products, teach or learn, participate in communities, and interact with research/creative tools.

## Marketplace principle

Users should be able to move through a transparent lifecycle: create → publish → discover → evaluate → transact → deliver → review → resolve issues. Financial, legal and identity-sensitive functions must use appropriate external infrastructure and compliance controls before production launch.

## Product principle

The platform should maximize useful value rather than merely maximize time spent. Retention metrics must be balanced with satisfaction, safety, accessibility, successful task completion, creator outcomes and complaint resolution.

## Scale vision

The project may retain an aspirational global audience target of 8.5 billion people, while public dashboards report measured users and verified metrics only. Aspirational targets must never be displayed as achieved results.
