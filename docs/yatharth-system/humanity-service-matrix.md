# Humanity Service Matrix

## Objective

Translate the Yatharth public-platform vision into measurable service areas while keeping philosophical claims separate from independently testable service outcomes.

| Service area | Public capability | AI/ML/NLP role | Human/independent control |
|---|---|---|---|
| Food | discovery, offers, community support | matching, translation, routing | providers, safety review |
| Housing | listings/resources | matching, accessibility | providers/legal process |
| Healthcare | information/service discovery | search, triage support, translation | qualified professionals |
| Education | courses/library/skills | tutoring, personalization | educators/content review |
| Employment | jobs/freelancing | matching, profile assistance | employer/user decisions |
| Economy | store/payments/earnings | fraud detection, support | financial/legal controls |
| Justice | complaint/process resources | classification, routing | authorized institutions |
| Nature | environmental data/projects | analysis, anomaly detection | domain experts/public authorities |
| Community | groups/content | moderation assistance | appeals/human review |
| Research | claims/evidence | extraction, comparison | independent reviewers |

## Operating principle

The platform should seek to increase access, safety, clarity, opportunity and ecological responsibility without claiming that an AI system can guarantee complete satisfaction for every person.

## Public dashboard

For each service area publish:
- availability
- coverage
- latency
- user satisfaction
- unresolved cases
- safety incidents
- independent review status
- known limitations

This prevents "fully autonomous" from becoming an unverifiable marketing claim.
