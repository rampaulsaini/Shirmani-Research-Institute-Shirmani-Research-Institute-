## Verification gates

Engineering modules move through:
DESIGNED -> IMPLEMENTED -> TESTED -> DEPLOYED -> MONITORED -> AUDITED

Scientific, philosophical or civilizational claims separately use:
AUTHOR_SOURCE -> NORMALIZED -> EVIDENCE_MAPPED -> INDEPENDENT_REVIEW -> VERIFIED / PARTIALLY_SUPPORTED / INCONCLUSIVE / NOT_VERIFIED

No engineering status may substitute for independent verification.
