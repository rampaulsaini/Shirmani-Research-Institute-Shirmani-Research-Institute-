This is an implementation specification, not a claim that every capability is currently live.

## Account capabilities

A registered user may, subject to applicable law and platform rules:
- create and manage a profile
- publish text, image, audio and video
- follow, communicate and participate in communities
- create a creator/business page
- offer lawful services
- list eligible digital products
- publish educational material
- create research/publication records
- receive reviews and service feedback
- manage purchases, orders and earnings
- control privacy, consent and notification settings
- request review or appeal moderation decisions

## Marketplace lifecycle

Create -> Submit -> Automated checks -> Publish/hold -> Discover -> Purchase/contract -> Deliver -> Review -> Support/dispute -> Settlement -> Audit.

## Content lifecycle

Upload -> identity/consent checks -> malware/media checks -> NLP classification -> policy checks -> provenance -> publication -> discovery -> feedback -> audit.

## AI-assisted discovery

Search, recommendations, translation, accessibility and marketplace matching may use AI/ML/NLP. Recommendations must remain explainable at an appropriate level and users should have meaningful controls.

## Customer value

The platform measures utility, quality, safety, accessibility, fairness, support and resolution. Engagement is not treated as the sole success metric.

## Status labels

Every capability must expose one of:
PROPOSED, DESIGNED, IN_DEVELOPMENT, TESTING, LIMITED_LIVE, LIVE, AUTOMATED, INDEPENDENTLY_REVIEWED.

Documentation, workflow execution or a passing CI check alone does not make a capability LIVE or VERIFIED.
