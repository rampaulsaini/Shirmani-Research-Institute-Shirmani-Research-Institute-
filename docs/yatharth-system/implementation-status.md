## Not equivalent to full production
Source files, schemas, workflows, or successful CI runs do not by themselves prove that a globally deployed social network, marketplace, payment/currency system, education service, or fully autonomous AI/ML/NLP operation is production-complete.

## Completion gates
PLANNED -> SPECIFIED -> IMPLEMENTED -> TESTED -> DEPLOYABLE -> DEPLOYED -> MONITORED -> INDEPENDENTLY REVIEWED.

## Verification rule
Independent verification remains distinct from engineering readiness. Automated tests can establish software properties but do not independently verify metaphysical, social, scientific, or policy claims.
