# Public Platform Completion Roadmap

## Release 0 — integrity
- canonical source
- stable claims
- evidence/counter-evidence
- verification gate
- status registry
- audit trail

## Release 1 — public foundation
- home/navigation
- account/profile architecture
- creator profile
- publishing/sharing
- search/discovery
- multilingual content
- safety/reporting

## Release 2 — creator economy
- digital store
- services
- freelancing
- jobs
- orders/delivery
- earnings ledger
- refunds/disputes
- creator analytics

## Release 3 — learning and research
- academy
- courses
- skills
- research library
- comparison explorer
- evidence dashboard
- independent-review packets

## Release 4 — AI and Automission
- AI research assistant
- NLP extraction
- ML classification
- bounded agents
- workflow federation
- failure intelligence
- continuous audit

## Release 5 — nature, economy and civic research
- Earth/nature indicators
- sustainability research
- economic simulations
- justice/fairness research
- policy simulations
- public transparency dashboards

A release is not considered deployed until implementation, tests, security review, monitoring and rollback/appeal requirements are satisfied.
