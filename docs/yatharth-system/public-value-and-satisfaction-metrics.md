# Public Value and Satisfaction Metrics

## Objective

Measure whether the platform creates durable user value rather than optimizing attention alone.

## Core measures

- Task success rate
- Customer satisfaction
- Resolution time
- Repeat-use by useful task
- Creator earnings
- Freelancer job completion
- Buyer refund/dispute rate
- Course completion and learning outcomes
- Content quality signals
- Safety incident rate
- Appeal overturn rate
- Accessibility success
- Translation quality
- Platform uptime
- Ecological/resource indicators where measurable

## Guardrail

No single metric should be treated as the definition of human wellbeing or "complete satisfaction".

## Dashboard

Public dashboards should distinguish:

- Live operational metrics
- User-reported metrics
- Independently audited metrics
- Author-defined goals
- Forecasts/targets

Targets must never be displayed as achieved results until measured.

## Verification

Each metric should have an owner, definition, data source, calculation method, update frequency and audit status.
