# Public Platform Service Contracts

Each public feature must expose a machine-readable contract covering:
1. Purpose
2. User roles
3. Inputs and outputs
4. Permissions and consent
5. Data provenance
6. Safety and abuse handling
7. Human appeal path
8. AI/ML/NLP responsibilities
9. Audit events
10. Failure and recovery behavior
11. Accessibility and localization
12. Metrics

## Core services
- Identity/Profile
- Social Publishing
- Search/Discovery
- Messaging/Community
- Research/Evidence
- Education
- Freelancing/Employment
- Marketplace/Store
- Creative/AI Music
- Economy/Payments
- Justice/Complaints
- Nature/Humanity
- Verification/Trust
- Notifications/Support

No service may silently convert an author claim, recommendation, prediction or AI output into a verified fact.
