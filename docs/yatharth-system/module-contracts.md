# Yatharth Module Contracts

Every module follows: **Input → Processing → Evidence/Rules → Human Boundary → Output → Audit → Status**.

## Core modules
- Source Preservation: immutable source snapshots and provenance.
- Claim Registry: stable claim IDs and lifecycle state.
- Evidence Map: primary/secondary sources plus counter-evidence.
- Independent Verification: qualified human review; fail-closed.
- AI/ML/NLP: extraction, classification, translation, clustering and research assistance with traceable sources.
- Automission: bounded workflow orchestration, retries, monitoring and audit trails.
- Public Platform: accounts, profiles, publishing, discovery and community.
- Creator Economy: products, services, freelancing, jobs, orders and earnings.
- Education: courses, learning paths, skills and research training.
- Media: audio, video, music, podcast and multilingual publication.
- Nature/Earth: indicators, projects, datasets and research.
- Governance: bounded authority, separation of roles, human review and appeals.

## Common requirements
Security, privacy, accessibility, rate limits, abuse prevention, observability, rollback, versioning and documented ownership are required before production activation.

## Prohibited shortcuts
AI output is not independent verification. Workflow success is not scientific verification. A public webpage is not evidence by itself. User engagement is not proof of user benefit.
