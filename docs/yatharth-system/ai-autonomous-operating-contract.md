# AI-Native Autonomous Operating Contract

## Objective
Provide continuous machine-assisted operation while preserving user agency, safety, auditability, and recoverability.

## Agent layers
- L1 Intake & identity-safe routing
- L2 NLP understanding and classification
- L3 Search, retrieval and semantic linking
- L4 Recommendation and matching
- L5 Creator, education, commerce and support agents
- L6 Trust, abuse, fraud and quality controls
- L7 Research/evidence/comparison agents
- L8 Automission supervisor and federation
- L9 Continuous audit, recovery and incident response

## Hard gates
AI must not silently:
- claim independent verification;
- convert an author assertion into scientific fact;
- execute irreversible high-impact account, financial, legal, or justice decisions without the required policy gate;
- expose private user data;
- bypass audit or appeal mechanisms.

## Operational states
Every public feature should be machine-readable as:
PLANNED -> IN_BUILD -> TESTED -> LIVE -> AUTONOMOUS_ASSISTED.

A feature is not considered LIVE merely because documentation exists. A feature is LIVE only after its interface, backend behavior, tests, security controls, and deployment are actually present.

## Success measures
Measure user value through:
- task completion
- service quality
- satisfaction
- safety incidents
- dispute resolution
- accessibility
- reliability
- creator/customer outcomes

Do not use time-on-platform alone as a proxy for success.
