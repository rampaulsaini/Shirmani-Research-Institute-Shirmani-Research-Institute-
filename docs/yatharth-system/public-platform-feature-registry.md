# Public Platform Feature Registry

Status vocabulary:

- PLANNED — specified but not implemented.
- IN_BUILD — implementation underway.
- TESTED — automated tests pass for the implemented scope.
- LIVE — deployed and publicly accessible.
- AUTONOMOUS — live operation includes bounded automated orchestration.
- HUMAN_REVIEW — requires human review for specified actions.
- VERIFIED — reserved for independently verified claims/evidence, not software completeness.

## Rule

A registry status must reflect repository/deployment evidence. Vision statements must never be rendered as live functionality.

## Scale target

The long-term vision may specify a target of 850 crore users/consumers, but this is an aspirational scale target, not a current user count or forecast.
