# Public Feature Registry

This registry is the canonical public-interface inventory. A feature is not considered live merely because its architecture, documentation, workflow, or CI check exists.

## Status vocabulary

- **PLANNED** — specified but not implemented.
- **BUILDING** — implementation underway.
- **BUILT** — code/artifact exists.
- **TESTED** — automated tests pass.
- **LIVE** — deployed and usable by public users.
- **AUTONOMOUS** — live with defined automated operation and monitoring.

## Truthfulness rule

The public UI must distinguish **architecture, implementation, deployment and independent verification**. A workflow success badge must never be presented as proof that a public service exists or that a substantive claim is scientifically verified.
