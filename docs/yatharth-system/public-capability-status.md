# Public Capability Status Contract

This document defines how public platform capabilities are reported without overstating implementation.

| State | Meaning |
|---|---|
| PLANNED | Defined as a product/module requirement |
| BUILT | Source implementation exists |
| TESTED | Automated/manual tests provide evidence of expected behaviour |
| LIVE | Deployed and usable by public users |
| AUTONOMOUS | Live capability is operated by monitored automation within defined boundaries |

## Reporting rule
A GitHub workflow run, successful CI check, documentation file, or Automission event does not by itself prove that a public product capability is LIVE or AUTONOMOUS.
