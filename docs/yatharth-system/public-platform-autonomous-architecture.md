## Intelligence layers
- NLP ingestion and semantic understanding
- ML ranking/recommendation
- agent task routing
- safety and abuse detection
- evidence retrieval and provenance
- translation and accessibility
- marketplace matching
- customer-support automation
- quality-control automation
- observability and failure intelligence
- Automission supervision
- cross-repository federation

## Operating loop
Observe -> Understand -> Classify -> Act/Recommend -> Verify -> Learn -> Audit -> Recover.

## Human-control boundary
Autonomous operation does not mean unaccountable operation. Account sanctions, financial exceptions, legal/justice outcomes, high-risk safety decisions and independent verification must have human review and appeal paths.

## Deployment rule
A feature is only labelled LIVE when the public interface, backend/data path, authentication, security, tests, monitoring and recovery path are actually deployed and tested. Architecture alone is not deployment.
