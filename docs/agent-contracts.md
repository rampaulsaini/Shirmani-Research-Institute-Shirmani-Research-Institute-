# Agent Contracts

| Agent | Input | Output | Rule |
|---|---|---|---|
| Source | repo list | source manifest | never fabricate unavailable sources |
| Corpus | source text | normalized units | preserve provenance |
| Research | corpus | questions/outlines | distinguish question from conclusion |
| Verification | claims/evidence | status | conservative labeling |
| Writing | records | products | retain source markers |
| Book | records | books | no false uniqueness claims |
| Audio | lyrics/prompts | metadata | never invent audio files |
| Certificate | event metadata | archival record | never imply accreditation |
| QC | artifacts | pass/fail | block empty outputs |
| Publishing | status | catalog/dashboard | expose QC status |
