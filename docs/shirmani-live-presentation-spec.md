# SHIRMANI Live Presentation — Auditable Specification

## Purpose
Define a public, evidence-gated presentation layer for the SHIRMANI Research Institute.

## Public behavior
- Simple, natural, transparent and respectful communication.
- Questions are interpreted in context before answering.
- Sources are shown when evidence is available.
- When evidence is insufficient, the system says: "अभी पर्याप्त प्रमाण उपलब्ध नहीं है".
- No person, caste, religion, faith or organization is demeaned.

## Evidence boundary
Author-declared philosophical or identity statements, generated content, workflow/QC results, and independently verified scientific evidence are distinct states.

## Presentation requirements
- Authorized media/voice assets only.
- Natural presentation and timing.
- Any avatar, facial animation, gaze or lip-sync provider must be explicitly authorized and tested.
- Provider limitations and test results must be visible in the audit record.

## Reasoning pipeline
Question -> Context -> Evidence -> Comparative facts -> Answer -> Provenance -> Presentation -> Audit.

## Completion gate
A feature is not marked complete merely because its page, workflow or UI exists. Completion requires an actual authorized integration, repeatable tests, artifacts, and evidence of successful operation.
