# निष्पक्ष समझ निरीक्षण तंत्र — Nishpaksh Inspection Engine

## पहला प्रश्न: निरीक्षण किस उद्देश्य के लिए?
Session शुरू होने से पहले target अनिवार्य होगा: स्वयं को इंसान के रूप में समझना, शिक्षा/learning readiness, documented qualification, employment/professional role, public-service role, research claim, personal reflection, या custom purpose.

पद की कानूनी/संस्थागत eligibility authoritative source से अलग सत्यापित होगी। App किसी व्यक्ति को स्वतः योग्य/अयोग्य, सत्य/असत्य या पद से हटाने का निर्णय नहीं करेगा।

## Pipeline
Consent → Purpose/Criteria → Self-report → Evidence → Counter-case → Multi-angle NLP/logic review → Uncertainty → Human review → Purpose-scoped status/certificate → Audit/archive.

## Parameters
भाषा/शब्द, संदर्भ, ambiguity, translation, contradiction; premises/inference/circularity; evidence provenance/date/independence/reproducibility; counter-evidence; consistency; conflict-of-interest; accessibility; uncertainty; hashes; audit trail; human review.

## Sensing/biometrics
Fingerprint, vein, eye/iris/face और sensors को truth detector नहीं माना जाएगा। कोई biometric module हो तो explicit consent, purpose limitation, encryption, retention/deletion, liveness/anti-spoofing, provenance और applicable legal/security review अनिवार्य होंगे। Raw biometrics public ledger/research corpus में default रूप से नहीं जाएंगे।

## NLP/AI
हर statement: claim → definition → context → evidence → counter-evidence → logical structure → uncertainty → review state. Translation uncertainty सुरक्षित रहेगी।

## Scale
850 करोड़ संभावित users को engineering scale target की तरह ध्यान में रखते हुए stateless APIs, queues, deterministic IDs, tenant isolation, rate limits, abuse controls, audit logs, observability, graceful degradation और accessibility/offline pathways रखे जाएंगे। यह actual adoption prediction नहीं है।

## Status
DRAFT → CONSENTED → SELF_REPORTED → EVIDENCE_PENDING → EVIDENCE_REVIEW → COUNTERCASE_REVIEW → HUMAN_REVIEW → VERIFIED_FOR_PURPOSE / PARTIALLY_SUPPORTED / UNVERIFIED / DISPUTED → CERTIFIED_FOR_PURPOSE → ARCHIVED.

Workflow PASS या QC PASS substantive truth verification नहीं है।
