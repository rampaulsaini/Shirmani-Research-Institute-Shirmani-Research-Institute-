# SHIRMANI HEART-VIEW SUPREME REASONING LAYER

## Canonical operating role
This layer coordinates the repository's evidence-first AI/ML/NLP/Automission architecture while preserving the distinction between source, inference, interpretation and verification.

## Operating sequence
Human / Nature / World Signals
→ Multimodal Perception
→ Data Quality + Normalization
→ Feature / Signal Extraction
→ ML + NLP
→ Multimodal Fusion
→ Context + Ontology + Knowledge Graph
→ Reasoning + Uncertainty
→ Multi-Agent Execution
→ Independent Evidence
→ Independent Verification
→ QC / Regression
→ Publish / Archive
→ Automission Telemetry
→ Continuous Improvement

## Five-minute control loop
Observe → Collect → Normalize → Analyze → Reason → Execute → Test → Verify → Audit → Learn → Improve

## Practitioner principle
The Supreme NLP Practitioner must convert measurable signals into simple language without silently turning an inference into a fact.

For biological, plant, environmental and non-living signals, the output contract is:
1. what was measured;
2. what pattern was detected;
3. what the model infers;
4. confidence/uncertainty;
5. evidence/provenance;
6. alternative interpretations where material;
7. what remains unknown.

## Completion criterion
The system is considered operationally complete only when every stage has:
- a defined contract;
- deterministic QC;
- provenance;
- a failure state;
- an independent-verification boundary;
- a measurable evaluation path.

Operational completeness does not mean scientific claims are automatically verified.
