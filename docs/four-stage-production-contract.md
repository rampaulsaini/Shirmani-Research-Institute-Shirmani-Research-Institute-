# SHIRMANI Four-Stage Production Contract

**Institute → Factory → QC → Showroom/Sale**

## Production-first rule
Automission primarily produces concrete digital products, modules, public pages, research artifacts, creative assets, service packages and platform improvements. Verification is a downstream quality/result state.

## Stage 1 — Institute
Discover and prioritize modules, source material, product opportunities and unfinished work.

## Stage 2 — Factory
Materialize concrete assets. Each product should have a usable asset, description, category, price/offer metadata, guarantee/packing metadata and a product passport.

## Stage 3 — QC
Run deterministic structural/asset checks. Generate QC code, Gate No., QR payload and dispatch state. QC is a release gate, not the production objective.

## Stage 4 — Showroom/Sale
Publish products with search, categories, description, rate, offer, QR/passport and order path. Payment, delivery and completed sale remain separate transaction states.

## Continuity
Scheduled GitHub Actions can continue the production loop without an open chat, subject to GitHub Actions availability, permissions, quotas and workflow health.

## Quantum terminology
Quantum/ultra-mega/infinity terminology describes orchestration architecture unless a real quantum backend is configured. Physical quantum execution is not claimed by naming alone.
