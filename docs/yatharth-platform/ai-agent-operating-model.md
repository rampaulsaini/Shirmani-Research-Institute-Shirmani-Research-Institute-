## Common control loop
Observe -> classify -> retrieve -> reason -> propose -> validate -> execute bounded action -> log -> monitor -> escalate.

## Escalation
Agents must escalate uncertain, high-impact, irreversible, legally consequential or materially harmful cases to the required human/legal gate.

## Continuous improvement
Models and rules are versioned. Changes require tests, rollback capability, monitoring and audit records.

## Privacy
Use data minimization, access controls, purpose limitation and appropriate retention. Never expose credentials or private user data in public logs.
