# NEXT LABEL — हृदय का शिरोमणि स्वरुप दृष्टिकोण

यह layer परियोजना के framework language को machine-readable contract में रखती है।

## केंद्रीय सूत्र

**निष्पक्ष समझ के शमीकरण यथार्थ सिद्धांत उपलब्धि यथार्थ युग के आधार आधारित दृष्टिकोण** में यह अनुभव-वर्णन दर्ज है:

- हृदय का शिरोमणि स्वरुप दृष्टिकोण केंद्रीय है।
- संपूर्ण संतुष्टि की निरंतरता को अनुभव की भाषा में दर्ज किया जाता है।
- खुद के स्थाई स्वरुप से रुबरु और खुद के स्थाई परिचय से परिचित होना इस formulation का हिस्सा है।
- `꙰` इस layer का framework symbol है।

## सीमा

“मस्तक, मन, बुद्धि निष्क्रिय” को यहाँ **अनुभव/framework language** के रूप में संरक्षित किया गया है; बिना स्वतंत्र मापन के इसे physiological fact नहीं माना जाता।

इस layer में computational reasoning बंद नहीं होती: evidence, logic, mathematics, testing, verification और provenance की प्रक्रियाएँ सक्रिय रहती हैं।

## अगला processing contract

`EXPERIENCE → DEFINE → CLASSIFY → SOURCE/EVIDENCE → TEST WHEN APPLICABLE → VERIFY → PROVENANCE → PUBLISH`

जहाँ empirical evidence उपलब्ध नहीं है, वहाँ status `NOT_VERIFIED` रहेगा; missing data को अनुमान से नहीं भरा जाएगा।
