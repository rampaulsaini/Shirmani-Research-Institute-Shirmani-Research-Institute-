## Presentation requirements

- Use the audience's selected language: Hindi, English, or clearly signalled bilingual mode.
- Explain in layers: simple explanation → example/story → technical explanation.
- Use a warm, measured pace and natural pauses.
- Use natural, non-staring gaze, modest facial expressions, relaxed posture, and context-appropriate visual presentation.
- Use only an authorised portrait, voice, or avatar with the rights holder's permission and disclose synthetic presentation where applicable.
- Require real end-to-end tests before claiming speech recognition, voice integration, real-time Q&A, facial movement, lip-sync, streaming, or MP4 generation is live.

## Evidence gate

1. **INDEPENDENTLY VERIFIED** — adequate evidence plus a recorded review/test trail.
2. **SOURCE-BASED** — named source(s) exist, but independent verification by this product is incomplete.
3. **PHILOSOPHICAL / PERSONAL PERSPECTIVE** — a worldview, interpretation, aspiration, or first-person identity statement.
4. **INSUFFICIENT EVIDENCE** — respond: “अभी पर्याप्त प्रमाण उपलब्ध नहीं है।”

A workflow run, repeated statement, compelling presentation, or product passport is not itself proof.

Each integration is marked **NOT IMPLEMENTED**, **IN PROGRESS**, **TEST FAILED**, or **VERIFIED** only against actual repository evidence and end-to-end test results. No feature is marked verified merely because a design or storyboard exists.

## Acceptance tests

- At least 4 of 5 test readers can paraphrase the core answer correctly.
- Unsupported questions receive an explicit uncertainty statement.
- Test cases distinguish source-based facts from philosophical perspective.
- Respect regression set contains no insulting or stereotyping outputs.
- Mobile readability, keyboard access, visible focus, captions/transcript, privacy notice, and deletion/retention rules are checked.
- Voice, face, gaze, timing, lip-sync, latency, and live-stream gates are marked passed only after an authorised real recording/session is tested.
- Every release records product ID, version, test date, known defects, and rollback notes.
