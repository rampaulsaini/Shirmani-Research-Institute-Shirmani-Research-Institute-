# SHIRMANI Product Review → Quality Improvement Loop

**Product → Public Showroom → Customer uses product → Rating/Review → Quality Backlog → Production Improvement → New Product Build → QC → Showroom**

Customer reviews are production feedback, not a substitute for independent scientific verification.

Each review records Product ID, rating, actual usage result, quality improvement request, optional reproduction/evidence, public issue URL and capture timestamp. The automation stores it as durable JSONL under generated/.

Future production controllers can prioritize repeated defects, low ratings, reproducible failures, missing descriptions, usability, accessibility and performance improvements.

A review is feedback evidence about user experience; it does not automatically prove scientific truth, model accuracy, safety, revenue, delivery or universal product quality.
