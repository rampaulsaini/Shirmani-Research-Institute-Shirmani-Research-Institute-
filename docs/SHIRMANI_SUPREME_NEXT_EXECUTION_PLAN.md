## Priority 1 — Build a minimal, testable presentation prototype
1. Prepare a static identity card using the original photo only, with aspect-ratio-preserving scaling.
2. Add the approved English identity line beneath the photo.
3. Implement a simple Hindi/English Q&A script with four evidence states: VERIFIED, SOURCE-BASED, PHILOSOPHICAL / IDENTITY, INSUFFICIENT EVIDENCE.

5. Integrate voice only after an authorized recording/provider is accessible.
6. Integrate photo/avatar lip-sync only after the original media and authorized tool access are available.

## Priority 2 — Product-specific showroom evidence
Every published product must have:
- Unique product name, ID, version, and intended-use description.
- A real product-specific VIP screenshot.
- A real product-specific demo video showing the actual tool in use.
- A QR code tested to open the matching long-form product passport.
- Usage instructions, requirements, limitations, support/contact path, and transparent price/offer terms.
- Test report and known-issues section.
- A feedback-to-improvement loop that respects consent and privacy.

A generic video, mock screenshot, untested QR code, or workflow run does not count as product-specific evidence.
