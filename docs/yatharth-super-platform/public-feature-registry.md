## Status contract

- ARCHITECTURE: specification exists; not proof of live deployment.
- IN_BUILD: implementation is underway.
- TESTED: automated tests pass for the defined scope.
- LIVE: deployed and externally usable.
- AUTOMATED: defined routine operations are automated.
- INDEPENDENTLY_REVIEWED: independent review exists for the specified claim or control.

No status may be upgraded merely because a GitHub workflow succeeds.
