# SHIRMANI Supreme NLP Evaluation Gate

## Purpose

Create a measurable gate between NLP development and any claim of improved accuracy.

## Required evidence

Every benchmark record must identify task and population scope, dataset fingerprint, model name and version, metric, baseline, measured result, uncertainty/confidence, provenance, limitations, and verification state.

## Improvement rule

A result is an improvement only when the same task definition and evaluation protocol support a reproducible comparison against a declared baseline.

The platform must not convert workflow success into model accuracy, QC PASS into independent verification, model confidence into truth, a single benchmark into universal capability, or a biological/environmental pattern into proof of subjective feeling or consciousness.

## Verification states

REGISTERED → UNVERIFIED → REVIEW → VERIFIED

BLOCKED is terminal until the blocking condition is resolved.

## Five-minute operating requirement

Automission may execute deterministic contract/evaluation gates every five minutes. Expensive model training, external data collection, or high-impact actions remain separately budgeted and authorized.

## Output contract

The NLP layer should produce measured signal, detected pattern, model inference, plain-language interpretation, confidence/uncertainty, evidence/provenance, alternative interpretation when material, and unresolved unknowns.
