4. Send one message manually from an authorised mailbox. The drafts above have not been sent.
5. Record timestamp and evidence only after the send actually occurs. Respect opt-outs; do not send repeated follow-ups when declined.
6. Record replies, quote requests, accepted scopes, deliveries, and settled payments as separate states. Only reconciled receipts count as realised revenue.
