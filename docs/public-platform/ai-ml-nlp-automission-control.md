# AI / ML / NLP / Automission Control Plane

L1 Intake • L2 Identity/Context • L3 NLP • L4 Discovery • L5 Safety • L6 Commerce • L7 Education • L8 Creator • L9 Research • L10 Verification Gate • L11 Support • L12 Audit • L13 Federation • L14 Automission Supervisor • L15 Recovery.

## Pipeline
Event → Context → NLP → Policy/Safety → Agent routing → Validation → Execution → Audit → User-visible result.

Routine reversible low-risk work may be automated within explicit policy. Irreversible or high-impact actions require appropriate human review, appeal or approval.

GitHub Actions, AI-agent orchestration, ML models and NLP services are distinct capabilities; workflow execution is not proof of a complete production AI/ML/NLP product.

Never place secrets or credentials in source, issues or logs.
