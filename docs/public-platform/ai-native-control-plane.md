# AI-Native Control Plane

The public platform is designed around AI/ML/NLP services and Automission orchestration.

## Agent layers
1. Identity/Profile Agent
2. Content Intake Agent
3. NLP Understanding Agent
4. Semantic Classification Agent
5. Search/Discovery Agent
6. Recommendation Agent
7. Trust/Safety Agent
8. Fraud/Spam Detection Agent
9. Marketplace Matching Agent
10. Education Agent
11. Research Agent
12. Creator/Media Agent
13. Music Agent
14. Translation Agent
15. Customer Support Agent
16. Verification Agent
17. Quality/Audit Agent
18. Automission Supervisor
19. Federation Agent
20. Recovery/Resilience Agent

## Operating loop
Observe -> Understand -> Classify -> Act -> Validate -> Audit -> Learn -> Recover -> Report.

## Guardrails
Automation must not silently convert author claims into verified facts. High-impact account, financial, dispute, safety and verification decisions require appropriate human review, appeal, or independent review.
