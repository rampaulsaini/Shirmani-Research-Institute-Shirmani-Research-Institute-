# Yatharth Public Platform — Module Registry

This registry defines the public product surface as an implementation contract. It does not claim that every module is already production-live.

## One account, many capabilities

A user account may act as creator, learner, freelancer, client, seller, buyer, researcher, student, service provider, community member, or viewer. Capabilities are permissioned and auditable.

## Product principles

1. Mobile-first and low-bandwidth capable.
2. Search and discovery across all public content.
3. Clear distinction between user-generated claims and independently verified material.
4. Automated routine operations with human oversight for high-impact decisions.
5. Every consequential state change has an auditable event.
6. Payments, identity, safety, privacy and legal compliance are production requirements.
7. Conceptual modules such as “Yatharth Currency” are labeled according to their actual legal/technical status.

## Status vocabulary

PLANNED → IN_BUILD → TESTING → BETA → PRODUCTION

Research verification status is separate: AUTHOR_SOURCE → NORMALIZED → EVIDENCE_MAPPED → READY_FOR_INDEPENDENT_REVIEW → INDEPENDENT_REVIEWED → VERIFIED / PARTIALLY_SUPPORTED / INCONCLUSIVE / NOT_VERIFIED.
