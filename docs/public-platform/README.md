## Account capabilities
A registered user may, subject to platform rules and applicable law:
- create and manage a profile;
- publish text, images, audio, video and other permitted content;
- follow, discover, comment, share and collaborate;
- create a store and list eligible digital products or services;
- offer freelance services;
- publish courses and educational resources;
- create music and media;
- participate in communities;
- purchase eligible products/services;
- view orders, earnings, reviews and activity.

## Public trust model
Content and claims are visibly separated into:
- Author Source
- Normalized Claim
- Evidence Mapped
- Comparative Review
- Independent Review
- Verified / Partially Supported / Inconclusive / Not Verified

No author-authored philosophical or experiential statement is promoted to independently verified fact merely because an AI workflow processed it.

## Product principle
The platform is designed around user value, satisfaction, safety, accessibility, discovery, creation, learning, opportunity and fair exchange. Engagement metrics must not override user safety, informed choice or legal requirements.

## Scale aspiration
The project may state an aspirational long-term target of 850 crore (8.5 billion) users/consumers. This is a goal, not a present user count or guaranteed outcome.

## Implementation rule
Every public feature must have a lifecycle:
Planned -> Built -> Tested -> Live -> Monitored -> Audited.
