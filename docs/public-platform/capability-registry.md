## Rule

A capability becomes LIVE only after implementation, tests, deployment path and public-facing contract satisfy the applicable gates. Workflow success alone does not make a public capability live.

## Autonomous operating loop

Observe -> Understand -> Classify -> Act/Recommend -> Verify -> Audit -> Recover -> Learn

The loop must preserve logs, provenance, permissions, rate limits, safety controls and appeal paths.

## Global scale principle

The long-term vision may target billions of users, but capacity claims must be measured from actual deployed infrastructure, reliability tests and observed usage rather than architectural intent.
