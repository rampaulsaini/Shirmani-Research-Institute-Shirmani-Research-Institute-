# Yatharth Global Public Interface v2

## Purpose

Define the public-facing experience for a unified social, knowledge, education, creator, marketplace, research and service platform.

The interface is a product architecture contract, not a claim that every capability is already deployed.

## Account model

Any eligible user can create an account and, subject to applicable law and platform rules:

- create a profile;
- publish text, images, audio, video and other supported content;
- follow, subscribe, collaborate and form communities;
- offer services and freelance work;
- list lawful digital products;
- create educational material and courses;
- create and distribute music and media;
- receive orders, reviews and support;
- maintain creator, learner, seller and service-provider dashboards.

## Core public loop

Create -> Publish -> Discover -> Learn -> Connect -> Collaborate -> Buy/Sell -> Deliver -> Review -> Improve.

## Public trust signals

Every material object should expose appropriate provenance and status:

- Author-provided
- AI-assisted
- Community-reviewed
- Evidence-mapped
- Independently reviewed
- Verified
- Disputed
- Restricted
- Removed

No automated status may silently convert an author statement into an independently verified fact.

## User value principles

The platform should optimize for durable user value rather than raw time-on-site:

- usefulness;
- learning;
- creativity;
- access to opportunity;
- affordability;
- safety;
- transparency;
- customer satisfaction;
- accessibility;
- environmental responsibility.

## Global scale target

The project may use 850 crore (8.5 billion) as a long-term aspirational reach target. It must never be presented as current users, guaranteed adoption, or a forecast.

## Deployment boundary

GitHub workflows, AI agents, ML/NLP pipelines, databases, payment systems and Automission remain implementation layers. Public UI must expose only capabilities that are actually available and pass the relevant readiness gate.
