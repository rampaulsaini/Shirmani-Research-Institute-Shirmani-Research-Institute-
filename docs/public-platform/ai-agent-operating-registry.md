# Yatharth AI Agent / ML / NLP / Automission Registry

## Operating architecture

### A1 — Identity & Account Agent
Profile setup assistance, onboarding, account support and preference handling.

### A2 — Social Content Agent
Content classification, formatting, translation assistance, discovery and creator tooling.

### A3 — NLP Understanding Agent
Intent, entities, topics, language detection, claim extraction and semantic normalization.

### A4 — Research Agent
Literature discovery, source mapping, evidence packets, citations and research task routing.

### A5 — Education Agent
Learning-path generation, tutoring assistance, assessment support and multilingual learning.

### A6 — Marketplace Agent
Product/service categorization, search, matching, catalog assistance and transaction workflow support.

### A7 — Freelancing / Employment Agent
Skill matching, opportunity discovery, proposal assistance and workflow coordination.

### A8 — Music / Creative Agent
Music, audio, media and creative workflow assistance with rights-aware boundaries.

### A9 — Trust & Safety Agent
Spam, abuse, fraud and anomaly signals; moderation assistance; escalation to accountable review.

### A10 — Justice / Appeals Support Agent
Evidence organization, case intake assistance, procedural guidance and appeal routing. It must not replace a court or make unreviewable legal judgments.

### A11 — Nature & Humanity Agent
Environmental/public-interest data aggregation, alerts, research and measurable stewardship dashboards.

### A12 — Economy Agent
Creator-income analytics, marketplace accounting assistance and transparent records. It must not represent a proposed Yatharth currency as legal tender without lawful implementation.

### A13 — Verification Agent
Claim/evidence consistency checks and independent-review packet preparation. It cannot independently certify its own outputs.

### A14 — Automission Supervisor
Schedules, dependencies, retries, queues, observability, recovery, federation and bounded execution.

### A15 — Continuous Audit Agent
Detects drift, broken contracts, failed workflows, missing evidence and status mismatches.

## ML/NLP lifecycle
Ingest → Normalize → Classify → Retrieve → Match/Reason → Execute bounded action → Evaluate → Audit → Learn/Update → Escalate.

## Fail-closed rules
- No self-certification as independent verification.
- No irreversible high-impact action solely from an unreviewed model output.
- No hidden financial commitment.
- No exposure of private user data beyond authorized purpose.
- No fabricated evidence, citations or outcomes.
- Model uncertainty must be retained where material.

## Human control
Human review remains available for rights, appeals, disputes, high-impact financial/legal/safety decisions and independent verification.
