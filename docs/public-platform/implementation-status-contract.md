# Public Platform Implementation Status Contract

## States

- PLANNED — specified but not implemented.
- BUILDING — implementation underway.
- TESTED — implementation passes defined tests but is not necessarily deployed.
- LIVE — available to users.
- AUTONOMOUS — live with bounded automated operation, monitoring and escalation.

## Required evidence

A status transition should have an implementation reference, test/CI evidence, deployment reference where applicable, responsible component, timestamp/version, known limitations and rollback path.

## Prohibited shortcuts

A design document, issue, pull request, successful unrelated workflow, generated content, CI pass without deployment evidence, or AI statement does not by itself prove LIVE or AUTONOMOUS status.

## Verification separation

Public platform readiness and substantive claim verification are separate dimensions. A sophisticated automated platform can exist while a philosophical or scientific claim remains INDEPENDENT_REVIEW_REQUIRED or NOT_VERIFIED.
