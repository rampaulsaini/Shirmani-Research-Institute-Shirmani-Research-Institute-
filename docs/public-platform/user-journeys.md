# Core User Journeys

## 1. Join → create → participate
Account → profile → language/preferences → publish → discover → follow/community → notifications.

## 2. Creator → customer
Creator profile → product/service/media listing → discovery → order → fulfilment/entitlement → support → payout (when production payment integration is available).

## 3. Freelancer → client
Skill profile → service listing → client request → proposal → agreement/milestones → delivery → review/dispute → payout.

## 4. Learner → capability
Course discovery → enrolment → lessons → practice → assessment → certificate (when configured) → portfolio/opportunity.

## 5. Researcher → evidence
Source intake → claim ID → normalization → evidence/counter-evidence → comparative analysis → independent review → status.

## 6. User → complaint → appeal
Report → triage → evidence collection → moderation/dispute process → decision → notification → appeal → audit trail.

## 7. AI task → Automission
Event → classify → route → execute bounded task → validate → log → retry/recover or escalate → publish result.

## 8. Global access
Language selection → accessible/mobile-first UI → low-bandwidth fallback → localized content → safe participation.

## Design principle
Optimize for useful outcomes and user satisfaction, not compulsive engagement. Provide clear controls, data portability and exit paths.
