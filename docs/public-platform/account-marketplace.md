# Account, Creator and Marketplace Layer

## Account
Core account objects:
- User
- Profile
- Preferences
- Content
- Following / connections
- Notifications
- Wallet / earnings view where legally and technically supported
- Orders
- Reviews
- Support tickets

## Create and share
Users can create, upload, publish, edit, archive and share eligible content. The platform should provide visibility controls and clear ownership/licensing terms.

## Sell
Eligible sellers can create listings for:
- digital products;
- audio/music;
- books and publications;
- courses;
- creative services;
- research services;
- freelance services;
- AI-assisted services.

Commerce must include listing review, price display, order state, delivery state, refund/dispute paths and seller/customer reviews.

## Freelancing
A marketplace can match:
Client -> Requirement -> Search/AI matching -> Proposal -> Agreement -> Delivery -> Review -> Payment/settlement.

## Education
Education can support:
Course -> Module -> Lesson -> Assessment -> Certificate/record.
Certificates must not imply accreditation unless an actual accrediting authority exists.

## Social layer
Public content may support feeds, search, recommendations, communities, comments and sharing. Recommendation systems must provide safety controls, reporting and meaningful user settings.

## Justice and disputes
Yatharth Justice is a research/product concept, not a substitute for courts or statutory authorities. The public layer should provide complaint intake, evidence submission, mediation/appeal workflows where appropriate, transparency records, and links to lawful external remedies.
