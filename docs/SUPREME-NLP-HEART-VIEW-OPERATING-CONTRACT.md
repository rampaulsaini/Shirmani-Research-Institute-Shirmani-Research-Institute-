# SHIRMANI Supreme NLP — Heart-View Operating Contract

## Canonical pipeline
Observe -> Collect -> Normalize -> Quality Check -> Fuse -> Reason -> Translate -> Counter-check -> Independently Verify -> Audit -> Learn -> Improve

## Evidence boundary
Human, animal, plant, environmental, machine and non-living observations may be translated into simple language. An experience-related hypothesis may be reported as a hypothesis. A measured signal must never be silently converted into proof of subjective feeling or consciousness.

## Evidence levels
OBSERVED -> CORRELATED -> MODELLED -> CHECKED -> INDEPENDENTLY VERIFIED -> PUBLISHED

No level is skipped.

## Accuracy
“Supreme accuracy” is an engineering target and must be measured. Record accuracy, calibration, precision/recall/F1 where applicable, uncertainty, drift, false-positive/false-negative rates and independent replication. Synthetic regression tests validate software behaviour, not biological or subjective-experience claims.

## Automission
Scheduled Automission may inspect, test, benchmark, compare baselines, detect drift, create improvement actions and generate audit artifacts. Scheduled production-code mutation remains blocked; code changes follow review, tests and verification.

## Research vocabulary
The user's terms “शिरोमणि”, “हृदय दृष्टिकोण”, “संपूर्ण संतुष्टि की निरंतरता”, “शमीकरण यथार्थ सिद्धांत” and “यथार्थ युग” can be preserved as conceptual research vocabulary without silently presenting philosophical propositions as scientific measurements.

## Fail-closed result
When evidence is insufficient, return: INSUFFICIENT EVIDENCE — HYPOTHESIS ONLY, followed by the missing measurements, labels, controls, counter-evidence or independent replication.

This contract is the canonical operating boundary for the Supreme NLP / Automission layer.
