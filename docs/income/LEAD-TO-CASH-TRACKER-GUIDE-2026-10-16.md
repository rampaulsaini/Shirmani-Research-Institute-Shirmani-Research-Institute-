## Qualification gate

A lead may move to **Ready for human review** only when all fields below are supported:
1. Official organisation website and permitted official contact route.
2. A specific, current, publicly evidenced need with URL and date checked.
3. A deliverable that fits current writing/research capability.
4. No invented relationship, credentials, outcomes or unsupported claims.
5. Price is either approved in the reconciled menu or explicitly marked **scope-first quote**.
6. Personalised message reviewed by a human; no bulk unsolicited sending.
7. Opt-out and follow-up status recorded.

## Stage definitions

- **Research needed:** not yet enough evidence to contact.
- **Qualified:** official source, relevant need and permitted route recorded.
- **Draft prepared:** tailored text exists; not sent.
- **Approved to send:** human reviewed the exact recipient, facts and message.
- **Sent:** sent copy and timestamp recorded.
- **Replied:** received reply recorded.
- **Enquiry complete:** objective, topic, language, word limit, deadline, sources and budget captured or explicitly marked to be agreed.
- **Quote sent:** written scope, price, timeline, revisions, usage rights and payment terms sent.
- **Accepted:** written client acceptance captured.
- **Payment verified:** cleared receipt checked; store only a non-sensitive reference here.
- **Delivered:** final deliverable link and delivery date recorded.
- **Closed / opted out:** no further outreach; retain minimum necessary status.

## Metrics

- Qualified prospects = rows with official-source evidence + specific need + checked date.
- Send rate = actually sent / approved-to-send, only if denominator > 0.
- Reply rate = replies / actually sent, only if denominator > 0.
- Quote acceptance = accepted orders / quotes sent, only if denominator > 0.
- Revenue = cleared payments actually received, never proposed or quoted amounts.
- Delivery completion = accepted orders delivered / accepted orders, only if denominator > 0.

Do not put passwords, OTPs, bank account details, identity documents or private client files in this public repository. Keep the live ledger private and access-controlled; this file is a blank schema and process guide.
