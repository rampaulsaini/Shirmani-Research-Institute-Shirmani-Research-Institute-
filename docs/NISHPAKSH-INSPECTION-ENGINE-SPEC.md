# निष्पक्ष समझ निरीक्षण Engine v1

## क्रम
उद्देश्य → मानदंड → claim normalization → evidence → counter-evidence → independent review → certificate status.

## Purpose
SELF_HUMAN, EDUCATION, EMPLOYMENT, SERVICE, PUBLIC_ROLE, RESEARCH.

## Parameters
Self-inspection; multilingual NLP; context/ambiguity/negation/temporality; contradiction detection; source provenance; documents; audio/video/vision; reproducible skill tests; logic/math; uncertainty; privacy; consent; audit trail.

## Biometric boundary
Finger-vein, iris/eye और अन्य biometric signals केवल lawful, necessary, consented, secure authentication/identity सहायता हो सकते हैं। वे truth, character, intelligence, ideology, competence या political suitability का प्रमाण नहीं हैं।

## High-impact boundary
System evidence organize और auditable report बना सकता है। यह स्वतः admission, employment, benefits, guilt, political eligibility, constitutional office eligibility या अन्य high-impact outcome तय नहीं करेगा। Public roles में केवल लागू official/legal criteria को evidence workflow में map किया जाएगा।

## Certificate state
REGISTERED → EVIDENCE_PENDING → AI_ASSISTED_REVIEW → HUMAN_REVIEW → VERIFIED / DISPUTED / REJECTED → ARCHIVED.

VERIFIED के लिए स्वतंत्र evidence, countercase, reproducible/testable support जहाँ लागू हो, reviewer role, timestamp और audit trail आवश्यक हैं।

## Subscription
Subscription सुविधा का भुगतान है, सत्य/योग्यता/certificate का नहीं।

## Scale
850 करोड़ users को capacity/design objective मानकर stateless clients, queues, rate limits, privacy controls, schema validation, observability और audit तैयार किए जाएँ। यह वर्तमान capacity का दावा नहीं है।

## Integrity
Workflow success ≠ research verification.
QC pass ≠ scientific proof.
Generated ≠ independently verified.
Biometric match ≠ truth/competence.
Certificate ≠ immunity from law or institutional review.
