# SRI-THINK-003 — Simple-to-Deep Explainer Studio

**Status:** Browser-local structured-draft tool, v1.0  
**Public URL after deployment:** https://rampaulsaini.github.io/Shirmani-Research-Institute-Shirmani-Research-Institute-/showroom/simple-to-deep-explainer-studio.html

## Included behavior
- Accepts topic/claim, audience, language, claim type, user-provided sources, available data and limitations.
- Produces twelve layers: core idea, plain explanation, story/analogy, causal map, technical breakdown, evidence register, uncertainty/counter-arguments, test plan, paper outline, teaching check, human/environment impact and release status.
- Supports copy and TXT export in the browser.
- Explicitly distinguishes analogy from evidence, a URL from verification, and a research outline from a published/peer-reviewed paper.
- Does not fabricate equations, numerical results, citations, or VERIFIED status.

## Limits
Deterministic browser-side scaffold. No external LLM, internet source retrieval, independent verification, equation derivation from validated data, publication, outreach, or payment integration. No server persistence.

## Improvement loop
Collect consent-based feedback; triage specific issues; update templates; test empty-input handling, Unicode, copy/download and evidence labeling; record version changes. Reviews are improvement signals, not proof of correctness.
