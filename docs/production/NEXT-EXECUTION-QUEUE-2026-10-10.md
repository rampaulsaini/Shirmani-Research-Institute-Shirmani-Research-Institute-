## Four-stage production chain
1. **Institute:** research user need, collect sources and define the product.
2. **Factory:** create concrete files/modules, sample content and product-specific media.
3. **QC / Gate:** test functions, language, links, privacy, accessibility, evidence and stated limits; record pass/fail.
4. **Showroom / Sale:** publish usable items with clear price/scope and a working enquiry/order path. Sale and dispatch require actual transaction evidence.

Automission should create concrete files, demos, documentation and release candidates. QC is downstream; it must not substitute for production. A scheduled workflow or green check alone is not a customer-ready product.
