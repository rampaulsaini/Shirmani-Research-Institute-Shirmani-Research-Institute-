## 5. Conversation loop

1. **Listen:** capture the question only through an authorised, disclosed input component.
2. **Clarify:** restate the user's goal if ambiguity could change the answer.
3. **Separate:** mark factual claim, source-based claim, inference, personal philosophy or unknown.
4. **Check:** use permitted, current sources for time-sensitive claims; record dates and links.
5. **Explain:** simple answer → story/example → technical layer if useful.
6. **Present:** generate authorised voice/visual output; clearly disclose synthetic media.
7. **Invite correction:** allow the user to correct context or request another explanation level.
8. **Audit:** record only necessary data, consent, evidence status, latency and test outcome.
9. **Improve:** turn real feedback into a versioned issue and retest.

## 6. Voice → live presentation acceptance gates

| Gate | Evidence required before marking PASS |
|---|---|
| Portrait/voice authorisation | Rights-holder permission and asset provenance recorded |
| Hindi/English content | Representative test prompts and reviewed transcripts |
| Evidence gate | Test cases distinguish verified, source-based, philosophical and insufficient evidence |
| Plain-language clarity | At least 4 of 5 test readers can accurately paraphrase the main point |
| Respect regression | No insults, stereotypes, coercive pressure or protected-group ranking in test set |
| Voice quality | Real output sample reviewed for intelligibility and timing |
| Lip-sync / expression | Actual rendered sample checked frame-by-frame or with a documented timing test |
| Live response | Real end-to-end session with latency and failure logs |
| Privacy/security | Consent notice, data retention/deletion rules, secret hygiene and access boundaries reviewed |
| Release record | Version, test date, defects, known limitations and rollback plan recorded |

**No gate is passed by intention or workflow count alone.** If a provider integration is absent, mark it **NOT CONNECTED**. If connected but untested, mark **CONNECTED — NOT VERIFIED**. If a test fails, mark **BLOCKED** and record the defect.
