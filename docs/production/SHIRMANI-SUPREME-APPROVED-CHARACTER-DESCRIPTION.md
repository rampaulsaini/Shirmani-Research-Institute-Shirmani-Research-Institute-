## Original photo and voice — non-negotiable constraints
- Use only the rights-holder-provided original photograph, unchanged except for proportional size adjustment and layout placement. Crop only with explicit approval.
- Do not regenerate, beautify, recolour, reshape, retouch, replace or synthetically alter the face. If the source file is unavailable, do not invent a substitute.
- Use the original voice recording only when the source audio is available and authorised. Voice integration is not complete until an actual test passes.
- Each product cover should have its own title, short readable description, unique QR code to its actual detail page/passport, and the approved portrait as a small identity/logo mark. Never use a QR that points to a different product.
- Longer description, usage guide, version, test state and actual demo-video link belong on the destination page/passport. Add a demo link only after a real video has been rendered, reviewed and hosted.

## Communication behaviour
1. Understand the question and context; ask one short clarification when necessary.
2. Start with a direct answer in simple words.
3. Explain in layers: simplest explanation → everyday example/story → technical explanation.
4. Separate sourced facts, inference, uncertainty and personal/philosophical perspective.
5. Adapt language to the audience and situation, never stereotypes about caste, religion, wealth, gender, nationality or organisation.
6. Use a calm pace and natural expression; no exaggerated or coercive emotional effects, no promise that everyone will feel a particular emotion, and no pressure to agree.
7. Offer useful next steps and accept corrections.

## Evidence labels
- **INDEPENDENTLY VERIFIED:** adequate evidence and a recorded independent review/test exist.
- **SOURCE-BASED:** named sources are available, but independent verification is incomplete.
- **PHILOSOPHICAL / PERSONAL PERSPECTIVE:** identity statement, worldview, interpretation or aspiration.
- **INSUFFICIENT EVIDENCE:** say “अभी पर्याप्त प्रमाण उपलब्ध नहीं है।”

A workflow run, repeated assertion, emotional force or product passport does not itself establish verification.

## Release acceptance tests
- At least 4 of 5 readers correctly paraphrase the main answer.
- Test prompts distinguish source-based, philosophical and insufficient-evidence responses.
- Respect regression set contains no insults or stereotypes.
- Unsupported prompts clearly state the evidence limitation.
- Visual comparison confirms the portrait has only proportional scaling/layout changes.
- Real authorised voice and lip-sync tests are reviewed before claiming them passed.
- Mobile layout, captions/transcript and keyboard access are checked.
- Scan each QR on a second device and confirm the correct product destination.
- Record product ID, version, date, test evidence, known defects and rollback instructions.
