# SHIRMANI Production Expansion — 2026-10-07

## Four-level production pipeline
1. INSTITUTE — discovery, research, source material and product opportunities.
2. FACTORY — concrete digital artifact production.
3. QC/GATE — identity, deterministic checks, version, QC code, gate and dispatch state.
4. SHOWROOM/SALE — public product page, short/long description, price/offer, order route, reviews and improvement.

## Visual identity
Every catalogue product should receive a stable ID, distinct visual identity, short description, product-specific route and QR route to the long description. The repository uses deterministic SVG masters because SVG is resolution-independent and scales beyond 4K. These are visual product cards, not photographic likenesses.

## Reviews
Customer reviews/ratings are inputs for usability, defect, description and prioritisation improvement. They are not scientific verification.

## Global usage
Offer browser-permission location display for the visitor's own current location. Do not covertly track or persist geolocation. Discover organisation official websites from public sources; do not label organisations as customers without evidence.

## Continuity
DISCOVER → SPECIFY → BUILD → PACKAGE → QC/GATE → SHOWROOM → EXPERIENCE → REVIEW → IMPROVE → BUILD AGAIN

Automation may run continuously while repository/workflow infrastructure is available. A fixed five-month or one-year completion guarantee cannot be honestly promised because quotas, permissions, dependencies, external services, funding and human/customer actions affect throughput.
