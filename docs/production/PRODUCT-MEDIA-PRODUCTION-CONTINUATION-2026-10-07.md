# SHIRMANI Product Media Production Continuation — 2026-10-07

## Production objective

Every concrete public product is progressively equipped with:

1. product-specific 4K visual identity;
2. short description on the visual;
3. upper-right QR route to the long description / Product Passport;
4. product-specific demo route and, where generated, real MP4 demo;
5. product-specific VIP Product Passport screenshot;
6. public price/offer and customer-facing usage information;
7. public review/rating feedback routed into quality improvement.

## Four-stage production

**Institute → Factory → QC/Dispatch Gate → Public Showroom**

Verification remains downstream of production. A workflow run, catalog entry, visual, demo, screenshot, or public page is not itself a sale, delivery, accreditation, or independent verification claim.

## Continuous production

The existing scheduled production workflows remain the execution layer. Media production must advance in bounded batches rather than stopping after one product.

## Scale

Current catalogue target: 5,000 concrete products.

Long-term catalogue architecture: 150,000+ products through sharding.

## Customer experience

The public showroom should let a visitor find a product, inspect its visual identity, read the short description, open the QR/long description, watch the demo when available, inspect the VIP presentation, see the published price/offer, and submit a review.

## Outreach boundary

Official company, government, science, and organisation links may be mapped in the directory. External outreach is only recorded as completed when an actual authorised outbound channel has performed it.

Generated media is customer education/presentation production, not scientific verification.
