## Required status vocabulary
- **PASS / VERIFIED:** reproducible test evidence is linked.
- **SOURCE-BASED:** cited source exists; independent verification is incomplete.

- **BLOCKED:** a required asset, permission, integration, or dependency is absent.
- **FAIL:** a test ran and did not pass.
- **NOT RUN:** no test result exists.
