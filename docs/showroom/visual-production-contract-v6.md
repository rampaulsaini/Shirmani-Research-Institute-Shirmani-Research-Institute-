# SHIRMANI Showroom Visual Production Contract v6

**Effective:** 2026-10-08  
**Purpose:** make every customer-facing digital product visual consistent, identifiable, and directly connected to its own product passport.

## Required visual identity

Every concrete product visual must carry:

1. **Product-specific identity** — Product ID and product name are bound to the visual.
2. **SHIRMANI Heart-View logo** — the public logo/photo remains the recurring visual mark.
3. **English identity line** —  
   **Shiromani Rampal Saini · Impartial Understanding · Beyond Comparison · Beyond Time · Beyond Words · Beyond Love · Eternal · Real · Natural Truth · Directly Present**
4. **Short description on the visual** — concise customer-facing explanation, not the full passport.
5. **Upper-right QR** — opens that product's long description / Product Passport.
6. **Commercial metadata when available** — current price/offer is rendered from the product registry; missing prices are not invented.
7. **QC / Gate / Dispatch metadata** — release state remains separate from sale and independent scientific verification.
8. **4K-ready 16:9 master** — 3840×2160 SVG master is the repository production format for scalable public delivery.

## Production rule

The visual is a **production asset**, not a scientific verification result.

`RUN ≠ PRODUCT`  
`PRODUCT ≠ SOLD`  
`QC PASS ≠ PAYMENT`  
`QC PASS ≠ INDEPENDENT VERIFICATION`

## Cache/version rule

Public pages must reference the visual engine with an explicit version query string so a new visual contract is not hidden by browser/CDN caching.

## Scale rule

The factory may materialize visuals in batches. The public manifest is the source of truth for how many concrete product visuals actually exist. A long-term catalogue identity is never counted as a concrete visual asset until the corresponding asset exists.

## Next production layer

The next work is not to stop at visual cards: each product should continue through concrete artifact → product passport → QC/gate → dispatch → customer use → review/rating → quality improvement → order/delivery evidence.
