# Supreme AI–ML–NLP–Automission Operating Contract

## Purpose
This contract turns the canonical Supreme AI–ML–NLP–Automission graph into a measurable, fail-closed operating system.

## Non-negotiable integrity rules
1. Accuracy is measured, never declared.
2. Source data, model inference, interpretation, confidence and uncertainty remain separate.
3. Preparation/QC is not independent verification.
4. A failed gate blocks publication or production change.
5. Automission may diagnose, test and propose improvements; consequential production changes require explicit approval gates.
6. No generated output is treated as proof of consciousness, subjective feeling or scientific truth without independent evidence.
7. Biological, environmental and non-living signals may be translated into plain language only as evidence-bounded interpretations.

## Five-minute control loop
Observe → Collect → Normalize → Analyze → Reason → Execute → Test → Verify → Audit → Learn → Improve

The scheduler is a quality-control trigger, not a claim that every stage completes within five minutes.

## Evidence contract
Every consequential result should carry:
- input/provenance
- transformation
- model/version
- output
- confidence
- uncertainty
- verification state
- timestamp
- audit reference

## Biological and environmental signal contract
For living organisms, plants, environments and non-living systems:

**measured signal → feature/pattern → model inference → interpretation → confidence → unresolved uncertainty**

The system must not silently convert a signal into a claim of subjective experience.

## Failure policy
**FAIL CLOSED → diagnose → record → retry safely → require verification before publication**

## Continuous improvement
Automission should prefer small, reversible, testable changes. Improvement is accepted only when regression checks remain green and evidence/provenance contracts remain intact.

## Maturity target
Data → NLP → ML → Multimodal Intelligence → Agent Collaboration → Independent Verification → Continuous Audit → Automated Improvement → Human Approval
