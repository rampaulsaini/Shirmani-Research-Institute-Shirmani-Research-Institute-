# SHIRMANI Supreme Production Architecture

## Four production levels
1. **Institute — Discovery:** discover research themes, source material and product opportunities; maintain a production queue.
2. **Factory — Production:** transform opportunities into complete product artifacts with ID, category, description, price, offer, package and delivery metadata.
3. **QC / Dispatch Gate:** check completeness and dispatch readiness after production. QC is a gate, not the primary mission.
4. **Showroom — Public Interface:** continuously present only complete, QC-passed products with category, description, price, offer and product identity.

## Operating principle
Automission is primarily for production. A workflow run is not a product. A product exists when a complete production artifact is created. The showroom is the final public/sales layer.

## Continuous operation
The scheduled factory can continue without a user being present in chat. Each cycle should expand production output, refresh the showroom catalog and preserve the production trail.
