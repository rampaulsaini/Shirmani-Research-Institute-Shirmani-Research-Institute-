## Important truth boundary

**25 / 1,016 = 2.46%** is a count ratio between underlying executable family engines and generated runnable identities. It is **not** a product-production percentage.

The 1,016 entries are factory/catalog identities with browser-runnable static MVP behaviour. They must not be represented as 1,016 independently built, uniquely packaged, sold, or independently verified commercial products.

The repository currently exposes **15 registered commercial offers**. A commercial offer is not evidence that the underlying audio, asset, service delivery, payment, or customer fulfilment has already occurred.

The previous statement that a **200 / 1,016 concrete-production overlay** existed is not retained here because the current repository evidence inspected on 2026-10-06 did not expose an authoritative source for that count.

### Priority C — verification
Keep independent verification fail-closed:
**Source → Claim → Evidence → Independent Test → Reproducible Result → Counter-Evidence → Independent Review → Audit → VERIFIED**

### Priority D — revenue evidence
Do not mark a product SOLD, DELIVERED, or REVENUE-GENERATING without transaction / fulfilment evidence.

## Truth rules

- **RUN ≠ PRODUCT**
- **CATALOG ≠ PRODUCED**
- **PRODUCED ≠ VERIFIED**
- **QC PASS ≠ INDEPENDENT VERIFICATION**
- **DISPATCH ≠ SALE**
- **OFFER ≠ SALE**
- **SALE ≠ REVENUE SETTLED** until settlement evidence exists
