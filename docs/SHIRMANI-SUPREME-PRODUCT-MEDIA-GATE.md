# SHIRMANI SUPREME — Product media release gate

This checklist is the product-level release contract. It does not claim the media already exists.

## Required for every individual product
- [ ] Unique product ID, name, version, and short description.
- [ ] Original owner-provided photo/logo asset located and verified; only proportional resizing and layout placement are allowed.
- [ ] English identity line beneath the photo/logo.
- [ ] Unique QR in the upper-right of that product's artwork.
- [ ] QR resolves to that product's own long-form passport, not a shared generic page.
- [ ] QR is scanned successfully on a mobile device and the destination is checked.
- [ ] Actual product-specific VIP screenshot captured from the real working product.
- [ ] Actual product-specific demo video recorded; a storyboard is not a video.
- [ ] Usage guide, version, known limits, and test/audit status published.
- [ ] Pricing, offer, and delivery promise reviewed before publication.
- [ ] Evidence state and release state recorded.

## Release states
- **DRAFT** — record is being prepared.
- **BLOCKED** — one or more required assets or tests are missing.
- **TESTING** — assets exist and checks are in progress.
- **VERIFIED** — all defined gates passed and evidence is linked.
- **PUBLISHED** — approved for public listing after verification.

Never set VERIFIED or PUBLISHED just because a workflow ran. A missing original photo, authorized voice recording, live avatar integration, real screenshot, or demo video remains explicitly BLOCKED / NOT PROVIDED. Do not fabricate a QR, screenshot, demo, customer review, sale, or outreach result.
