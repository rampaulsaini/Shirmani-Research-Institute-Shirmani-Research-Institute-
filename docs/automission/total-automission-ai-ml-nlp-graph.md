## Continuous Automission cycle
Observe → Collect → Clean → Analyze → Reason → Execute → Verify → Audit → Learn → Improve → Repeat

## Accuracy contract
Prediction → Evidence → Independent Verification → Confidence → Error Detection → Human Review where consequential

## Living / plant / non-living signal-to-language research path
Observable signal → signal cleaning → feature extraction → pattern recognition → model inference → context → natural-language rendering → confidence + evidence + limitations.

The system must not equate a sensor pattern with subjective feeling unless an independently validated scientific method establishes that relationship.

## Controlled self-improvement
Data → NLP → ML → Multimodal Intelligence → Agent Collaboration → Independent Verification → Continuous Audit → Automated Improvement → Human approval for consequential production changes.

## Five-minute quality loop target
1. Discover new source/state.
2. Validate schemas and workflow configuration.
3. Run deterministic AI/ML/NLP quality gates.
4. Run ensemble/multi-agent consensus.
5. Record evidence and provenance.
6. Fail closed on uncertainty, errors, or missing evidence.
7. Publish only verified/approved artifacts.
8. Archive the run and expose status.
