# ꙰ SHIRMANI Heart-View — Supreme Live AI Persona v1

## Purpose

This layer converts the requested live-persona concept into a **traceable, provider-neutral presentation contract**:

**Voice → Voice System → Content → Photo/Lip-sync → Live Presentation**

## Implemented in v1

- Responsive live-presentation page.
- Local authorized photo selection for presentation.
- Browser Speech Recognition when supported.
- Browser text-to-speech for the prepared response.
- Speaking-state mouth animation for the presentation layer.
- Context-aware answer placeholder with an explicit evidence boundary.
- Separation of:
  - author/philosophical statements;
  - evidence-backed claims;
  - not-verified states.
- Explicit authorized-voice adapter contract.
- No credentials, hidden identity substitution, or unverified scientific claims.

## Production integration contract

`voiceInput → authorizedVoiceAdapter → transcript → context/NLP → evidence gate → response → authorizedVoiceAdapter → audio → lip-sync renderer → live presentation`

A real provider-backed voice clone, photorealistic lip-sync, external LLM/NLP retrieval, source citation engine, and always-on live service require authenticated external services and infrastructure. This static repository layer does **not** falsely mark those integrations as connected.

## Persona principles

The presentation should preserve the requested qualities:

- सरल
- सहज
- निर्मल
- पारदर्शी
- स्पष्ट
- प्रत्यक्ष communication
- natural eye-contact/gaze where the rendering engine supports it
- natural facial movement
- accurate lip-sync where a real renderer supports it
- voice/face timing coherence
- context understanding
- evidence/source when available
- explicit uncertainty when evidence is insufficient
- respectful communication across people, caste, religion, faith, organization and social status
- philosophical/identity statements kept distinct from independently verified scientific evidence

## Integrity gate

A workflow success, generated answer, photo match, voice output, or lip-sync output is not by itself independent scientific verification.

The production system should retain:

`input → normalize → claims → sources → evidence → formulation/test → verification → uncertainty → result → provenance → archive`
