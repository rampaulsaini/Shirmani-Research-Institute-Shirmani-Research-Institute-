# SHIRMANI Supreme NLP Multimodal Operating Contract

## Objective

Provide a fast, reproducible and evidence-preserving bridge from heterogeneous
signals to simple-language explanations while keeping observation, inference,
uncertainty and independent verification separate.

## Pipeline

observe -> normalize -> quality -> align -> compare -> infer -> abstain/translate -> verify -> audit

## Controls

1. Every observation retains modality, feature, value, quality and source.
2. Raw measurement and model inference are separate evidence classes.
3. Conflicting observations are preserved and may block a claim.
4. Empty or unusable input produces NO_CLAIM.
5. Confidence is a bounded heuristic until calibrated against labelled data.
6. Every record receives a reproducible fingerprint.
7. Independent verification is mandatory before VERIFIED.
8. This control plane does not authorize production-code mutation.
9. Fluent sensor-to-language output cannot establish subjective experience.
10. Scientific claims require operational definitions, labelled datasets, controlled tests and independent replication.

## ML/NLP adapter path

Future models may replace deterministic feature extraction, classification,
fusion or translation only when they preserve provenance, calibration status,
uncertainty, abstention, evidence class, reproducibility and independent-verification compatibility.

## Automission acceptance

The five-minute conveyor accepts a cycle only when compilation, schema parsing,
validation, regression tests and the fail-closed promotion boundary all pass.
Generated candidates remain UNVERIFIED and cannot be promoted by this workflow.

The target is not merely fluent output. The target is traceable, testable and
reproducible language grounded in observable evidence.
