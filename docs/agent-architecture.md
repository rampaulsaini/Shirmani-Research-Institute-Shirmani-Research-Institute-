# ꙰ Multi-Agent Research Factory

Pipeline: Source Agent → Corpus Agent → Research Agent → Verification Agent → Writing Agent → Book/Audio/Certificate Agents → QC Agent → Publishing Agent.

Each stage exchanges structured records and preserves provenance. User-authored philosophy, hypotheses, source-backed statements and independently verified claims remain separate.

Free-first mode uses Python and GitHub Actions. GitHub documents scheduled/manual workflows and Python setup on hosted runners. External AI models are optional; free compute still has service and runtime limits.

The 100,000-record target is a production target, not a claim that every record is a unique independently authored insight.
