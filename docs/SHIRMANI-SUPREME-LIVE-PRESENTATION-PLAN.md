# SHIRMANI Supreme Live Presentation

This feature branch defines the public Live Presentation layer for the main hub.

## Flow
Voice -> Context -> Evidence -> Response -> Visual Presence -> Feedback -> Improvement

## Required behavior
- Simple, respectful, transparent communication.
- Natural presentation cues where the selected media/backend supports them.
- Source-backed answers when evidence exists.
- Say `अभी पर्याप्त प्रमाण उपलब्ध नहीं है।` when evidence is insufficient.
- Keep author/philosophical statements separate from independently verified scientific evidence.

## Media architecture
- Browser speech is a presentation fallback, not a personal-voice identity claim.
- Authorized personal voice requires an authorized media/backend integration.
- Photo/video and lip-sync require an authorized visual/animation backend.
- GitHub Pages alone does not provide persistent AI/ML/NLP inference or high-fidelity live lip-sync.
