ईमानदार क्षमता-सीमा: यह पेज किरदार का brief, rehearsal script और release checklist बनाता है। यह स्वयं HeyGen login/session नहीं पढ़ता, external API call नहीं करता, voice clone नहीं बनाता, MP4 render या live stream नहीं करता। किसी भी integration को सफल test और वास्तविक output मिलने पर ही VERIFIED मानें।
Voice / Text→ Context→ Evidence gate→ Response→ Authorized photo/voice→ Lip-sync→ Live→ Audit

1 · किरदार का व्यवहार

पहले सुनना

प्रश्न, भाषा, आशय और परिस्थिति समझना। अस्पष्टता से उत्तर बदलता हो तभी एक छोटा clarification प्रश्न पूछना।

सरल से गहरा

पहले रोज़मर्रा का उदाहरण; फिर कारण, तर्क, प्रमाण, सीमाएँ और आवश्यकता होने पर विशेषज्ञ-स्तर की गणना।

निष्पक्षता और सम्मान

जाति, धर्म, आर्थिक स्थिति या विचार के आधार पर अनादर नहीं। सहमति पाने के लिए दबाव, डर या भावनात्मक निर्भरता पैदा नहीं करना।

प्रमाण और दर्शन अलग

व्यक्तिगत/दार्शनिक विचार को उसी रूप में दिखाना। वैज्ञानिक दावे के लिए उपयुक्त स्रोत और जाँच आवश्यक।

2 · अपनी प्रस्तुति की rehearsal बनाएं

यहाँ rehearsal script बनेगी। यह draft है, स्वतंत्र तथ्य-जाँच या live avatar output नहीं।

3 · अधिकृत फ़ोटो और आवाज़ की तैयारी

आपकी माँग के अनुसार वास्तविक मूल फ़ोटो को बदले बिना ही पहचान के लिए उपयोग करना है। केवल अनुमति-प्राप्त मूल फ़ोटो/रिकॉर्डिंग चुनें। इस browser preview में चुनी फ़ाइल आपके डिवाइस पर ही दिखाई जाती है; यहाँ कोई server upload नहीं होता।

चेहरा generate, reshape, beautify, recolour या retouch नहीं किया जाएगा।

कोई आवाज़ sample चयनित नहीं।

यह page audio को clone या play नहीं करता। वास्तविक voice/avatar provider में अलग से consent और integration test चाहिए।

4 · Live readiness gates

किसी checkbox का चयन केवल आपकी checklist है; यह वास्तविक test अपने-आप नहीं चलाता।

स्थिति: NOT VERIFIED — आवश्यक test records अभी दर्ज नहीं किए गए।

5 · वास्तविक next steps

  1. इस brief से script और acceptance criteria तैयार करें।
  2. HeyGen या चुने हुए अधिकृत provider में स्वयं login करके photo/voice asset जोड़ें; यहाँ login credentials न डालें।
  3. Test Q&A, voice, face, lip-sync और final video को वास्तविक रूप में बनाएं।
  4. Generated artifact और test record को दर्ज कर मानव समीक्षा करें।
  5. सभी critical gates pass होने पर ही “VERIFIED” कहें।
