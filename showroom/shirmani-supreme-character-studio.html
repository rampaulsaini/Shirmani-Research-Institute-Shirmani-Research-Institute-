Release stages

V1 → V4

V1 · Specification: character profile, evidence labels, acceptance tests.

V2 · Local prototype: local media preview and manual checklist.

V3 · Provider integration: authorized provider connection, API/configuration, successful Q&A and media generation evidence.

V4 · Live release: latency, privacy, accessibility, security, human review, rollback and monitoring gates pass.
