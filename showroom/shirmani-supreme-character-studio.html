4. Measurable acceptance gates

Communication

  • 5 स्तर: एक-वाक्य सार → सरल उदाहरण → तर्क → स्रोत → तकनीकी विवरण
  • सम्मानजनक भाषा की manual review
  • प्रश्न का intent सही समझने का परीक्षण

Voice / face

  • अधिकृत asset और अनुमति रिकॉर्ड
  • voice provider का सफल test run
  • face movement और lip-sync का measured sample
  • latency और timing report

Evidence / release

  • स्रोत, तारीख और provenance दर्ज
