सत्यापित स्थिति: PROTOTYPE — NOT A LIVE AVATAR

यह पेज एक वास्तविक, चलने योग्य browser prototype है। यह HeyGen से connected नहीं है, अपने-आप ईमेल नहीं भेजता, असली voice clone/lip-sync/live stream नहीं बनाता और किसी external integration को verified नहीं बताता।

1. मूल फोटो / आवाज़ asset gate

मूल फोटो: ASSET REQUIRED
मूल अधिकृत आवाज़: ASSET REQUIRED

संलग्न MP4 को रिकॉर्डिंग-प्रक्रिया का संदर्भ माना गया है; वह अपने-आप original voice file या completed avatar integration का प्रमाण नहीं है। मूल तस्वीर को बिना retouch/face alteration के ही इस्तेमाल करना है।

Asset state तभी बदले जब वास्तविक फाइल और अनुमति जाँच ली जाए।

4. Local media review — photo / voice / video

फाइलें इसी browser में preview होती हैं; यह पेज उन्हें GitHub या किसी बाहरी सेवा पर upload नहीं करता। चयनित फाइल केवल candidate asset है—उससे ownership, authorization, identity या provider integration अपने-आप VERIFIED नहीं होते।

कोई फोटो चयनित नहीं।
कोई audio चयनित नहीं।
कोई video चयनित नहीं।

समीक्षा में दर्ज करें: क्या यह मूल asset है? अनुमति किसकी है? क्या फोटो हूबहू है? क्या आवाज़ स्पष्ट है? क्या video में वास्तविक generated/exported result और lip-sync दिखाई देते हैं? प्रमाण न हो तो BLOCKED / NOT VERIFIED रखें।

5. Acceptance gates

  1. मूल portrait और authorized voice asset की पुष्टि।
  2. Speech recognition और test Q&A के वास्तविक outputs सुरक्षित करें।
  3. स्रोत/प्रमाण और “अभी पर्याप्त प्रमाण उपलब्ध नहीं है।” वाला negative test पास करें।
  4. फोटो पहचान, natural movement, gaze, lip-sync और audio/video timing का end-to-end परीक्षण।
  5. QR, product passport, वास्तविक screenshot और playable product-specific demo जाँचें।
  6. सभी परिणाम, तारीख, failure और reviewer के साथ audit record रखें।

Release rule: critical gate fail = NOT VERIFIED.
