मापने के नियम

  • Evidence-complete: stage के लिए evidence URL/note + cycle ID + reviewer तीनों भरे हों। यह URL की सत्यता का स्वतः प्रमाण नहीं है।
  • Verified: reviewer ने वास्तविक output देखकर status verified किया हो; सिर्फ़ link या configuration पर्याप्त नहीं।
  • Release readiness: सभी 8 stages verified और evidence-complete हों, तथा release review approved हो तभी 100%।
  • अलग-अलग परीक्षण: voice authorization/audio, content/script, avatar identity, rendered video, lip-sync, Q&A, provider response और privacy/release checks एक-दूसरे के विकल्प नहीं हैं।
  • Data handling: records इस browser के localStorage में रहते हैं। JSON/CSV नियमित रूप से export करें; यह shared database या 24/7 monitoring नहीं है।
