  • Workflow cycle: एक GitHub Actions run; run होना सफल काम नहीं।
  • सफल cycle: conclusion success होना चाहिए।
  • वास्तविक उत्पादन: तैयार artifact/published deliverable का स्थायी link और QC record चाहिए।
