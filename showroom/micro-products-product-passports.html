Release and evidence status

सही स्थिति: repository में प्रत्येक linked tool की HTML file मौजूद है। नीचे दिए गए acceptance checks manual execution के लिए हैं; इन्हें चलाए बिना PASS नहीं माना जाना चाहिए। वास्तविक captured screenshots, recorded MP4 videos, external security audit, payment/checkout और customer sales evidence इस documentation change से नहीं बनते।
  • Product identity: stable product ID and direct demo link.
  • Usage guide: steps and a simple test case for each utility.
  • QC gate: run the listed checks in a real browser and record the result before claiming PASS.
  • Media gate: capture a real screenshot and record a narrated MP4 separately; no placeholder is represented as real media.
  • Commercial state: free browser utility unless a specific written offer is published; no sale or revenue is claimed.

Demo recording recipe (manual)

  1. Open the tool from its direct test-drive link in a desktop or mobile browser.
  2. Show the product name and ID, then enter the sample input described in its passport.
  3. Demonstrate the expected result and one invalid/edge case when applicable.
  4. Capture a real screenshot after the result appears; do not use a mockup as a product screenshot.
  5. Record a short MP4 walkthrough with the browser UI and narration; verify playback before marking it complete.
  6. Run the acceptance check again after any code change and record date, browser, result and issue link.

Suggested file naming: SRI-TOOL-00X-v1.0-demo.mp4 and SRI-TOOL-00X-v1.0-screenshot.png. These are naming conventions, not files that already exist.

SRI-TOOL-001 · VERSION 1.0

Word & Character Counter

Text utility to count words and characters before submitting a document, post or short brief.

Open tool: Word Counter test drive

How to use

  1. Open the tool and enter: Hello world.
  2. Confirm the displayed word and character counts update as documented by the interface.
  3. Try an empty input, extra spaces and a line break; confirm the result stays understandable.

Acceptance record

Manual check: common text, whitespace and empty input. QC: NOT RUN HERE

Limits: counts text only; does not proofread, translate or assess writing quality.

Demo narration

“I enter a short sentence, observe the word and character totals, then check how whitespace affects the count.”

Percentage Calculator

Basic percentage calculations for learning, everyday arithmetic and simple planning.

Open tool: Percentage Calculator test drive

How to use

  3. Try zero and a decimal input; note how invalid or unsupported inputs are handled.

Acceptance record

Manual check: known arithmetic, decimal and zero/invalid input. QC: NOT RUN HERE

Limits: not financial, tax, legal or investment advice; verify important calculations independently.

Demo narration

“I calculate ten percent of two hundred, compare the result with a known answer, and try a boundary input.”

SRI-TOOL-003 · VERSION 1.0

Length Unit Converter

Converts supported length units for study, design and everyday reference.

Open tool: Unit Converter test drive

How to use

  1. Choose a source and destination unit from the available options.
  2. Convert a known value, for example 1 metre to centimetres; expected result is 100 cm if both units are supported.
  3. Try zero and a decimal value; confirm units remain visible in the result.

Acceptance record

Manual check: known conversion, unit selection and decimal input. QC: NOT RUN HERE

Limits: only the units implemented by the page are supported; do not assume every scientific unit is included.

Demo narration

“I select two length units, enter a known value and check the conversion and displayed unit labels.”

SRI-TOOL-004 · VERSION 1.0

JSON Formatter & Validator

Formats JSON and helps identify syntax errors in structured text.

Open tool: JSON Formatter test drive

How to use

  1. Paste {"name":"SRI","active":true}.
  2. Run the formatter/validator and inspect the formatted structure.
  3. Remove a closing brace and confirm invalid JSON is reported rather than silently treated as valid.

Acceptance record

Manual check: valid object, malformed JSON and empty input. QC: NOT RUN HERE

Limits: JSON syntax validation does not establish that data is truthful, safe or correct for an application.

Demo narration

“I format a valid JSON object, then remove a brace to show the invalid-input response.”

Customer feedback and release record

Before publishing a QC PASS, record the tester, date/time, device/browser, steps run, expected and actual result, screenshot/video path, known issues and linked fix. Keep customer feedback separate from verified test results.

Suggested release states: NOT RUN → TESTING → PASS / FAIL → FIXED → RETESTED → RELEASED. A release should not be marked PASS solely because an HTML file exists or a workflow ran successfully.

Do not add invented ratings, customer reviews, sales, revenue or independent verification claims. Add a customer review only with genuine feedback and appropriate consent.
