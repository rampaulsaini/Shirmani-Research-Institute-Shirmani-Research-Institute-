# Yatharth Evidence Answer Kit
**Version:** 1.0.0 · **Edition:** Free starter · **Category:** Research & Education

## Purpose
A reusable kit for answering questions without confusing source-backed statements, personal interpretation, and independently checked claims.

## Included
- Question brief template
- Source log CSV
- Answer review checklist
- Product-specific demo video script

## How to use
1. Copy `templates/question-brief.md` and state one focused question.
2. Record sources in `templates/source-log.csv`, including publisher, date, URL, claim supported, and limitations.
3. Draft an answer and link factual claims to source records.
4. Label each claim SOURCE-BASED, INDEPENDENTLY CHECKED, INTERPRETATION, or INSUFFICIENT EVIDENCE.
5. Only use INDEPENDENTLY CHECKED when a second reviewer can reproduce the check.
6. Complete the checklist before publication and correct unsupported claims.

## Limitations and readiness
This is a working template kit, not an automated research engine, scientific database, legal opinion, certification, or guarantee of correctness. It does not yet browse automatically, call AI APIs, generate an MP4, create QR codes, or process payments. Demo script exists; rendered video does not. Independent external audit is not claimed.
