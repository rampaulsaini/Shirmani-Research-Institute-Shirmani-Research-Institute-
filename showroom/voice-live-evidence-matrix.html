सत्यापन के आठ अलग चरण

Voice source & consent

NOT VERIFIED

मौजूदा अधिकृत voice source का reference, अनुमति/अधिकार और source provenance दर्ज करें।

Evidence: source ID, consent/rights record, reviewer और timestamp.

Voice system

NOT VERIFIED

वास्तविक audio input/output, language handling, intelligibility और error behavior को चलाकर जाँचें।

Evidence: test ID, input/output artifact, transcript, latency और reviewer.

Content & dialogue

NOT VERIFIED

उत्तर की सटीकता, संदर्भ, सरल भाषा, स्रोत/अनिश्चितता और harmful output checks जाँचें।

Evidence: prompt, transcript, expected criteria, actual result.

Authorized avatar asset

REFERENCE ONLY

पहले से दिया गया HeyGen video reference रखा गया है। इस लिंक से अकेले source image/audio rights या identity fidelity प्रमाणित नहीं होती।

पहले से उपलब्ध HeyGen reference खोलें

Rendered media artifact

NOT VERIFIED

Provider job/export को चलाकर वास्तविक output video/audio file और playable URL दर्ज करें।

Evidence: job ID, artifact URL/hash, export timestamp, duration.

Lip-sync & audio QC

NOT VERIFIED

Actual video पर mouth/audio alignment, clipping, intelligibility, captions और mobile playback review करें।

Evidence: reviewer result, defects, retest and artifact reference.

Live Q&A

NOT VERIFIED

वास्तविक live session में spoken question → recognized text → answer → spoken response → avatar playback जाँचें।

Evidence: session ID, timestamps, transcript, latency, failure/recovery test.

End-to-end release gate

BLOCKED UNTIL EVIDENCE

एक ही test run में सभी कड़ियों के IDs/artifacts आपस में जुड़ें; कोई missing gate हो तो release रोकें।

Evidence: run ID, all artifact references, independent reviewer and signed release decision.

Review checklist (इस browser page का अस्थायी progress)

किसी box को तभी चुनें जब संबंधित वास्तविक प्रमाण उपलब्ध हो और reviewer ने उसे देखा हो। यह checklist server पर save नहीं होती और अपने-आप प्रमाण उत्पन्न नहीं करती।

अभी 0/8 स्थानीय checklist items चुने गए हैं।

Integrity rule: Reference link, design/mockup, workflow run, generated counter या checklist completion अपने-आप में वास्तविक आवाज़, lip-sync, live Q&A, independent verification, sales या income का प्रमाण नहीं है। वास्तविक artifacts और test records के बिना स्थिति NOT VERIFIED ही रहेगी।
