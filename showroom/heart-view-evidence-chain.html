अगले वास्तविक कदम

  1. Protected main पर direct push न करें। Production publisher के PR-based fix को mergeability, Actions policy और generated paths के विरुद्ध review करें।
  2. एक bounded production batch चलाएँ; generated JSON validation, QC summary, PR link और merged commit दर्ज करें।
  3. Public homepage को mobile पर खोलकर links और published-page smoke test दर्ज करें।
  4. HeyGen external test में voice, dialogue, lip-sync और live session के प्रमाण अलग-अलग जोड़ें। पहले से साझा reference link का उपयोग करें; उपयोगकर्ता से वही photo/video दोबारा न माँगें।
  5. Sales dashboard में drafts, deliveries, replies, orders और settled revenue अलग counters रखें।
