# Voice-to-Presentation Runbook

**Product ID:** VOX-006 · **Version:** 0.1.0 · **Readiness:** Specification

## End-to-end test sequence
1. Confirm microphone permission and speech-to-text accuracy.
2. Test context retention and question answering.
3. Check evidence handling and insufficient-evidence wording.
4. Configure only an authorized voice provider and test consent/rights.
5. Check captions, audio output, facial animation, and lip-sync.
6. Measure end-to-end latency and recover from interruptions.
7. Run respectful-communication and privacy regression tests.

## Limitations
No voice provider, face model, or live service is automatically connected by this document. Demo video not yet published.
