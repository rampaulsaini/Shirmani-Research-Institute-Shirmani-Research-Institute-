Release rules

  • A storyboard is not a video; a visual brief is not a screenshot; a QR URL is not a generated QR image.
  • QC_PASSED requires documented tests and no unresolved critical defect.
  • PUBLISHED requires a working product page and an honest customer-facing description. Price can be “quote after scope” when not fixed.
  • Count an order or sale only with real, dated transaction evidence; this desk never invents revenue.
  • Use only authorised security testing. Do not automate unsolicited mass contact or bypass opt-outs.
