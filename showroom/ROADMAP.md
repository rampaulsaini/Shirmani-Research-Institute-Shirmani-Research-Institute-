# Yatharth Showroom — Production Roadmap

This roadmap prioritizes tangible products and visible deliverables over workflow-count inflation.

## Release 1 — Starter product kit
- [x] Yatharth Evidence Answer Kit guide
- [x] Question brief template
- [x] Source log template
- [x] Answer review checklist
- [x] Product passport
- [x] Demo script
- [ ] Record and review an actual MP4 demo
- [ ] Generate a product-specific QR code pointing to the public product page
- [ ] Run a second-person usability review and record findings

## Release 2 — Product Passport & QC Gate
- [x] Specification and release-state definitions
- [ ] Executable schema validation for every product passport
- [ ] Automated link and deliverable checks
- [ ] Product-specific QC report and release history

## Release 3 — Showroom product expansion
For each next product, require a real deliverable, short description, intended user, usage guide, price/offer policy, visual identity, passport, demo script/video status, limitations, and feedback route. Do not count a name or placeholder as a finished product.

Suggested first categories:
1. Yatharth Learning Planner
2. Impartial Understanding Dialogue Cards
3. Supreme Skill Practice Tracker
4. Digital Product Brief Generator
5. Voice-to-Content Production Checklist

## Release 4 — Scale and integration
- Shard catalogue data by category and stable product ID.
- Add search, pagination, and a product detail route before targeting 150,000 records.
- Add customer feedback only with moderation, privacy notice, and spam controls.
- Integrate external AI/ML/NLP providers only through configured secrets, usage limits, logging controls, and documented tests.
- Add checkout only after payment provider setup and test transactions.
- Generate MP4 files only through a real renderer and retain render logs.
- Keep the public site and repository source in sync; confirm GitHub Pages source and deployment workflow before claiming a live release.

## Release-state vocabulary
- DRAFT: concept only
- FACTORY: work in progress
- QC_HOLD: failed or incomplete release gate
- QC_PASS: documented checks passed
- SHOWROOM: public listing with deliverables
- WITHDRAWN: no longer offered

QC_PASS is not the same as independent scientific verification. Do not invent reviews, sales, warranties, partner links, or test results.
