स्थिति: TESTABLE BROWSER PROTOTYPE — NOT A LIVE AVATAR

यह पेज स्थानीय browser में फोटो, रिकॉर्डिंग, speech recognition (यदि browser समर्थन करे), संवाद-रूपरेखा और चार versions की जाँच के लिए है। यह HeyGen API से कनेक्ट नहीं है, अपने-आप voice clone/lip-sync नहीं बनाता और किसी test को सफल घोषित नहीं करता। चुनी गई फाइलें इस पेज पर स्थानीय रूप से preview होती हैं; इस demo में server पर upload नहीं होतीं।

1. मूल फोटो — हूबहू

अभी कोई मूल portrait चुना नहीं गया। आपकी रिकॉर्डिंग में दिख रहा चेहरा एक screen recording का frame है; इसे अपने-आप साफ़ मूल portrait नहीं माना जाएगा।

किसी भी फोटो पर retouch, face alteration या अनधिकृत बदलाव नहीं किया जाता। इस prototype में फोटो चयन की स्थिति ही दर्ज होती है।

2. अधिकृत आवाज़ — रिकॉर्ड / सुनें

सिर्फ अपनी आवाज़ या स्पष्ट अनुमति वाली आवाज़ रिकॉर्ड करें। ब्राउज़र microphone अनुमति माँगेगा।

रिकॉर्डिंग शुरू नहीं हुई।

अभी कोई audio asset चुना/रिकॉर्ड नहीं किया गया।

3. आवाज़ से टेक्स्ट — browser capability test

यदि browser Web Speech API समर्थन करता है, तो यह आपके microphone speech को text में बदलने का प्रयास करेगा। यह AI reasoning या voice cloning नहीं है; परिणाम browser/provider के अनुसार बदल सकता है।

Speech recognition अभी नहीं चलाया गया।

4. संवाद एवं evidence-gate परीक्षण

परीक्षण शुरू करने के लिए प्रश्न लिखें। यह outline template है, किसी external AI model का generated answer नहीं।

अभी कोई संवाद परीक्षण नहीं हुआ।

5. चार versions — स्पष्ट readiness

V1 · Character

संवाद शैली, सरल भाषा, उत्तर रूपरेखा और evidence labels.

इस पेज पर स्थानीय रूप से परीक्षण योग्य

V2 · Voice

अधिकृत audio, microphone recording और browser speech-to-text capability check.

Provider voice model: NOT CONNECTED

V3 · Face + Lip-sync

मूल portrait और generated avatar video का review.

Lip-sync: NOT RUN — generated output आवश्यक

V4 · Live + Audit

Live Q&A, latency, failure handling, disclosure और audit trail.

Live integration: NOT CONNECTED

6. Acceptance checklist

  • फोटो: मूल file पहचानी गई, face alteration नहीं।
  • आवाज़: रिकॉर्डिंग/चुनी गई file चलती है और अनुमति स्पष्ट है।
  • Speech-to-text: browser support और वास्तविक output दर्ज।
  • संवाद: सरल और technical level पर प्रश्न परीक्षण।
  • Evidence: तथ्य-संबंधी दावा स्रोत से जुड़ा; प्रमाण न हो तो “अभी पर्याप्त प्रमाण उपलब्ध नहीं है।”
  • Avatar/lip-sync: वास्तविक provider output और audio-video review के बिना NOT VERIFIED।
  • Live: वास्तविक end-to-end test और माप दर्ज होने तक NOT CONNECTED।
