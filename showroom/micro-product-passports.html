SRI-TOOL-001 · TEXT

Word & Character Counter

शब्दों और अक्षरों की लंबाई जाँचें।

Use: text डालें; word/character counts देखें; खाली और बहु-पंक्ति text भी जाँचें।

  • Sample: “नमस्ते world”
  • Check: empty input, spaces, punctuation, emoji and Devanagari text.
  • Limit: यह readability, factual accuracy या quality का मूल्यांकन नहीं करता।

Percentage Calculator

Use: ज्ञात values दर्ज करें और result को स्वतंत्र गणना से मिलाएँ।

Shared acceptance checklist

  • Open every tool from its link on Android mobile and desktop.
  • Test normal input, empty input, invalid input, long input and keyboard-only use where applicable.
  • Check console/runtime errors and verify copy/download controls.
  • Record tester, date, browser/device, expected vs actual result and issue link before changing QC to passed.
  • Record an actual product-specific screenshot and MP4 demo before marking media-ready.
