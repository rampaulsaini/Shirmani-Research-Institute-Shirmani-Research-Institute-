नया उत्पादन / परीक्षण रिकॉर्ड

एक बार काम पूरा होने या परीक्षण चलने पर एक रिकॉर्ड दर्ज करें। सफलता और प्रमाण अलग-अलग हैं; प्रमाण लिंक/ID के बिना कोई चक्र प्रमाण-सहित पास नहीं गिना जाएगा।

भुगतान को आय में तभी जोड़ा जाएगा जब “हाँ” चुना गया हो और राशि शून्य से अधिक हो। गुणवत्ता स्कोर उपयोगकर्ता द्वारा दर्ज माप है, स्वतः स्वतंत्र प्रमाणन नहीं।

गुणवत्ता एवं प्रमाण के मानक

सफलता दर

सफल दर्ज चक्र ÷ कुल दर्ज चक्र × 100। चल रहे/रुके/विफल चक्र हर बार denominator में हैं।

प्रमाण-सहित पास

सफल चक्र जिनके साथ प्रमाण लिंक या run ID है ÷ कुल दर्ज चक्र × 100। यह बाहरी प्रमाण की वैधता अपने-आप नहीं जाँचता।

औसत QC स्कोर

केवल भरे गए QC स्कोर का औसत। खाली स्कोर को शून्य नहीं माना जाता।

स्रोत सत्यापन

GitHub CI, HeyGen वीडियो, voice, lip-sync, dialogue, live Q&A और भुगतान के लिए अलग-अलग प्रमाण दर्ज करें। एक का प्रमाण दूसरे का प्रमाण नहीं है।

चक्र लॉग एवं दैनिक रिपोर्ट

नवीनतम रिकॉर्ड पहले। रिपोर्ट दिन के अनुसार रिकॉर्ड गिनती दिखाती है, 24/7/365 uptime का दावा नहीं।

सुरक्षित संचालन नियम

  • कोई रिकॉर्ड हटाने से पहले JSON निर्यात रखें; यह पेज केवल इस ब्राउज़र की स्थानीय प्रतिलिपि रखता है।
  • पासवर्ड, API keys, access tokens, निजी ग्राहक डेटा या भुगतान कार्ड विवरण प्रमाण फ़ील्ड में न डालें। केवल सार्वजनिक artifact URL या गैर-संवेदनशील run ID दें।
  • रुकावट को हटाने से पहले उसका कारण और निर्भरता दर्ज करें। सुरक्षा जाँच को निष्क्रिय करना सुधार नहीं है।
  • वास्तविक live counters के लिए authenticated server/API, access control, timestamps, audit log, retention policy और monitoring integration की आवश्यकता होगी।
