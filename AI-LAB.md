# ꙰ SHIRMANI AI LAB

## Mission
A modular research-and-creation laboratory built on the repository's existing provenance, evidence, QC and factory infrastructure.

## Core layers
1. Source Layer — protected user source and traceable external sources.
2. Knowledge Layer — canonical records, concepts, claims and evidence.
3. Reasoning Layer — SHIRMANI HEART-VIEW SUPREME REASONING LAYER.
4. Verification Layer — human/audit review and fail-closed promotion.
5. Agent Layer — specialized agents with explicit contracts.
6. Tool Layer — reusable micro-tools and utilities.
7. Product Layer — applications, documents, datasets and services.
8. Media Layer — image, audio, video, film, animation and cartoon workflows.
9. Publication Layer — web, GitHub Pages, downloadable and archival outputs.

## Agent families
Source Librarian; Canonicalization; Concept Mapping; Claim/Evidence; Reasoning; Countercase; Verification Assistant; Language; Audio; Visual Direction; Storyboard; Media Metadata; Publication; Archive/Provenance; Quality-Control.

## Agent contract
Each agent declares input schema, output schema, source requirements, provenance requirements, deterministic tests, failure states, uncertainty behavior and version.

## Fail-closed principle
An agent returns NOT_VERIFIED, INCOMPLETE, DEFERRED or UNAVAILABLE when required evidence or execution results are missing. It must not manufacture completion.

## AI software catalogue
The lab can host or register local Python utilities, browser-based tools, static web applications, workflow agents, data processors, research dashboards, media automation scripts, API adapters, evaluation harnesses and reproducibility tools.

External AI models may be optional dependencies. The repository remains usable without a paid model wherever deterministic local processing is sufficient.

## Research boundary
Generated philosophical, artistic or explanatory material remains distinguishable from independently verified empirical claims. The lab supports exploration, reasoning and communication; it does not manufacture proof.
