# SHIRMANI HEART-VIEW SUPREME REASONING LAYER

## Preservation Contract

This document establishes the preservation boundary for the user's source material and the
SHIRMANI HEART-VIEW SUPREME REASONING LAYER.

### 1. Exact-source preservation
User-authored source wording must be preserved as source material. It must not be silently
rewritten, normalized, paraphrased, translated, corrected, or merged into derivative material.

### 2. Provenance
Every preserved source unit should remain traceable to its originating source, stable
provenance identifier, collection/batch context, and ingestion record whenever those fields
are available.

### 3. Source vs derivative separation
Interpretations, summaries, translations, analyses, metadata, classifications, generated
records, and AI-derived reasoning must remain explicitly separate from protected source text.

### 4. Evidence discipline
A source statement is not automatically an independently verified factual claim. Generated
records must retain appropriate evidence status and human-review requirements.

### 5. Integrity
Canonical records, source manifests, metadata, content hashes, and quality-control gates
must be deterministic and fail closed where integrity requirements are not satisfied.

### 6. Continuation rule
Future work should extend the existing architecture rather than overwrite protected source
material. New layers must preserve backward traceability.

### 7. User phrase
The requested layer name is preserved exactly as:

**SHIRMANI HEART-VIEW SUPREME REASONING LAYER**
