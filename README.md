## Research Integrity & Public Navigation

यह Research Institute तीन अलग-अलग परतों को स्पष्ट रूप से अलग रखता है: **सामग्री (content), संचालन/ऑटोमेशन (operations), और प्रमाण/सत्यापन (evidence & verification)**। किसी generated page, workflow success, QC result या archive record को अपने-आप स्वतंत्र वैज्ञानिक सत्यापन नहीं माना जाता।

### मुख्य सार्वजनिक मार्ग

- **Main Hub:** [index.html](index.html) — संस्थान का मुख्य प्रवेश बिंदु।
- **Research Factory:** [factory-dashboard.html](factory-dashboard.html) — factory/control और उपलब्ध status artifacts की दृश्यता।
- **Federation:** [federation-dashboard.html](federation-dashboard.html) — cross-repository observability layer।
- **Repository Network:** [repositories.html](repositories.html) — वर्तमान managed repository inventory का navigation।
- **Continuity:** [PROJECT-CONTINUITY.md](PROJECT-CONTINUITY.md) — architecture, evidence contract और अगली implementation priorities।

### Status semantics

| स्थिति | अर्थ |
|---|---|
| **READY** | आवश्यक artifact और execution wiring उपलब्ध हैं। |
| **REGISTERED** | stage घोषित/पंजीकृत है; continuous external execution का प्रमाण नहीं। |
| **PASS / CHECK** | किसी विशिष्ट generated batch का QC state। |
| **NOT_VERIFIED / UNAVAILABLE** | वर्तमान evidence उपलब्ध या स्वतंत्र रूप से सत्यापित नहीं है। |

**Integrity principle:** जहाँ evidence नहीं है वहाँ value नहीं गढ़ी जाती। Source, provenance, uncertainty और verification state को downstream content से अलग रखा जाता है।

### वर्तमान विकास दिशा

Source → Normalize → Claims → Sources → Evidence → Formulation/Test → Verification → QC → Publication → Archive

यह संरचना user-authored framework और generated research material को सुरक्षित रखते हुए traceability, reproducibility और स्पष्ट public presentation को प्राथमिकता देती है।
