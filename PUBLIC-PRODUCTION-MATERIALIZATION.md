## External catalogue

Existing audio/certificate/short catalogue entries remain visible, but are explicitly marked `CATALOG_EXTERNAL` and `EXTERNAL_PATH_UNVERIFIED` where the actual asset is outside this repository. The platform does not manufacture an asset-present claim.

## Production rule

A workflow run is not a product. A module-production card is not automatically a customer product. A product becomes public production when a real artifact or explicit delivery route is attached.

## Quality loop

Customer usage → reviews → ratings → improvement backlog → next production cycle.

Independent scientific verification remains a separate downstream integrity state and does not replace product production.

## Automation objective

Multi-layer AI/ML/NLP Automission should continuously discover work, produce artifacts, package them, expose them publicly, and feed customer feedback into improvement. Where a real quantum backend is not configured, the system must not claim that quantum hardware is executing the work.
