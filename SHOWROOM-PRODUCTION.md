# Production-first Showroom

The public production path is now explicitly modeled as:

1. **Institute** — research/discovery and product specification.
2. **Factory** — creation of the actual digital artifact.
3. **QC Gate** — quality, version and dispatch metadata attached to the artifact.
4. **Public Showroom** — customer-facing catalogue, price, offer, description and acquisition route.

## Important distinction
Automation exists to produce useful work. Workflow execution is not itself a product, and verification is not a substitute for production. Public reviews/ratings are improvement inputs; independent scientific verification remains a separate integrity layer.

## Current seed catalogue
The showroom exposes four existing catalogue entries and links them to the existing public store. Catalogue prices should be reconciled with the actual checkout/payment flow before being treated as final transactional prices.
