Scale

Current catalogue is automatically sharded into 500-product JSON files. The architecture supports the current 5,000 production target and the long-term 150,000 catalogue target without requiring one giant public JSON payload.

A catalogue identity is not automatically a concrete product, sale, or independent scientific verification.

Product routes

Each directory record can expose its own visual, demo/usage route, VIP screenshot, Product Passport and concrete artifact route. Official organisation links are shown only when supplied by product metadata.

Outreach state is queue-only: this repository does not claim that any company, government body or scientific organisation has been contacted unless an authorised external channel records that action.
