4. AI/ML/NLP Supreme reasoning map

Observe → Collect → Normalize → Context → Reason → Compare → Evidence → Answer → Verify → Audit → Learn → Improve
  • Measured signal, model inference, interpretation, confidence और uncertainty अलग रखे जाएँ।
  • Workflow success को model accuracy या independent verification न माना जाए।
  • Comparative claims के लिए operational definition, comparand, sources, counter-evidence और reproducible test आवश्यक हों।
  • हर उत्तर में जहाँ आवश्यक हो provenance और uncertainty दिखाई जाए।

5. “हर पल चेहरे पर मुस्कान…” — visual direction

मंच के presentation layer में warm, welcoming और dignified visual language रखी जाएगी; facial expression को किसी वास्तविक मानसिक अवस्था का प्रमाण नहीं बताया जाएगा। लक्ष्य है natural presentation: coherent gaze, facial movement, speech timing और lip-sync.
