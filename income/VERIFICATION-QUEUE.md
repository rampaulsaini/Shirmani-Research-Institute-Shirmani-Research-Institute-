# Income Verification Queue

This queue is the controlled boundary between research and execution.

## Verification checklist

For every opportunity:

1. Open the retained source URL.
2. Confirm the source is reachable and current.
3. Confirm the opportunity description matches the source.
4. Record evidence and the verification timestamp.
5. Keep the record UNVERIFIED until evidence has been reviewed.
6. Only owner approval can move an opportunity toward execution.
7. Never treat estimated value as actual income.

## Evidence minimum

A verification record should retain:

- opportunity ID
- source URL
- source checked timestamp
- evidence summary
- evidence location or citation
- verifier status
- owner approval state

No evidence means no execution.
