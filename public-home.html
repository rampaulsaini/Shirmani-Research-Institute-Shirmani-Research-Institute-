सत्यापन और भरोसा / What is—and is not—verified

  • Working demo: वही browser feature जो वास्तव में चलकर जाँचा गया हो।
  • Planned: specification या roadmap; इसे live feature न समझें।
  • External integration: provider configuration और end-to-end test evidence के बाद ही verified.
  • Sales: भेजे गए प्रस्ताव, ग्राहक की स्वीकृति, भुगतान और आय अलग-अलग दर्ज होंगे। अनुमान को बिक्री नहीं कहा जाएगा।

Login/signup, shared user accounts, global-scale social networking, live AI, email/WhatsApp sending, checkout, HeyGen live Q&A और NVIDIA infrastructure को तभी उपलब्ध बताया जाए जब वे वास्तव में जुड़े हों और परीक्षण पास करें।
