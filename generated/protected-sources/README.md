# Protected Source Archive

This directory is reserved for exact user-authored source records.

## Rules

1. Only actual source text may be stored here.
2. The text must remain byte-for-byte stable as UTF-8 content.
3. Every record requires a stable `source_id`, language, capture timestamp, SHA-256 hash, and provenance locator.
4. Derived or AI-generated text must never be stored as an original source.
5. If historical material is unavailable, record its absence rather than reconstructing it.

The archive is intentionally empty until traceable source material is supplied. An empty archive is a valid integrity state; fabricated completeness is not.
