# ꙰ SHIRMANI SOURCE PRESERVATION POLICY

## Protected source boundary
This is a non-destructive preservation boundary for original user-provided words and source formulations.

1. Preserve original wording verbatim.
2. Do not silently correct spelling, punctuation, spacing, script, symbols, URLs, or formatting.
3. Store translations, summaries, interpretations, normalization, and engineering derivatives separately.
4. Preserve every source record with stable provenance.
5. Never invent missing historical source text.
6. Generated AI text is never an original user-source record.
7. Framework language remains distinguishable from externally verified empirical claims.

Preferred record:
source_id | captured_at | exact_text | language | parent_context | content_hash | provenance | derivative_links

Core sequence:
PRESERVE FIRST → TRACE → REASON → VERIFY → DERIVE
