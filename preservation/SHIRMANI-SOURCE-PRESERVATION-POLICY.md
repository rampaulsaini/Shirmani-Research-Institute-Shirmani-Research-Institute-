# ꙰ SHIRMANI SOURCE PRESERVATION POLICY

## Protected source boundary
This directory is a preservation boundary for original user-provided words and source formulations used by the Shirmani Research Institute.

### Non-destructive rules
1. Original source text MUST be preserved verbatim.
2. Do not silently correct spelling, punctuation, spacing, language, script, symbols, URLs, or formatting.
3. Every derivative MUST be stored separately and labeled as derivative.
4. Missing historical source text MUST remain missing; never reconstruct it by invention.
5. Every derivative must retain a stable link to its source record.
6. Source records are append-only in intent; existing originals must not be overwritten by derivatives.
7. Generated AI text is never an original user-source record.
8. Framework language remains distinguishable from externally verified empirical claims.

## Preferred source record
source_id | captured_at | exact_text | language | parent_context | content_hash | provenance | derivative_links

## Integrity principle
PRESERVE FIRST → TRACE → REASON → VERIFY → DERIVE
