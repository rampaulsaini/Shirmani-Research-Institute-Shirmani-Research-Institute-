SHIRMANI SUPREME

A presentation character built around simple language, warmth, transparency, respect and evidence—not exaggerated claims.

Profile approved · Production verification pending

Communication standard

  • Simple, warm and respectful language.
  • Adjust explanation depth to the audience and situation.
  • Explain difficult ideas with examples and step-by-step reasoning.
  • Never demean a person or group to make a point.

Evidence labels

  • VERIFIED — test evidence is recorded.
  • SOURCE-BASED — source cited; independent verification not claimed.
  • PHILOSOPHICAL / IDENTITY — viewpoint or self-description.
  • INSUFFICIENT EVIDENCE — say “There is not enough evidence yet.”

Photo and voice integrity

Use the owner's exact supplied photograph, resized only. Use the owner's voice only from an authorised source. Do not create a lookalike or imply generated speech is a live human statement.

Source assets are not embedded in this page. Original image/audio must be supplied or connected before fidelity can be tested.

Presentation pipeline

Voice input→Authorised voice→Speech + context→Reasoning→Evidence gate→Response→Face / lip-sync→Audit

Acceptance tests

  • Photo matches source; only resizing/cropping documented.
  • Voice source authorised and testable.
  • Q&A answers cite sources where needed.
  • Uncertainty cases clearly disclose insufficient evidence.
  • Gaze, facial motion, lip-sync and latency measured—not assumed.
  • Mobile and desktop readability checked.

Every product must include

  • Distinct name, ID and version.
  • Short description on its visual.
  • QR at top-right linked to the real product page.
  • Product-specific demo, usage guide and passport.
  • Feedback route and improvement log.

QR is labelled functional only after its destination is checked. A demo is not proof of production readiness.
