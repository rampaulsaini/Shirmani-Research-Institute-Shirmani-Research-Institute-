01 • पहले तय करें: निरीक्षण किस लिए है?

किसी भी assessment से पहले उद्देश्य चुनना अनिवार्य है। उद्देश्य बदलने पर criteria, evidence और analysis भी बदलेंगे।

उद्देश्य चुनने पर आवश्यक निरीक्षण parameters यहाँ दिखेंगे।
किसी व्यक्ति की मानव गरिमा, मूल अधिकार या राजनीतिक पसंद इस app के score से तय नहीं होगी। सार्वजनिक पदों के लिए केवल लागू, प्रकाशित और role-relevant criteria तथा उपलब्ध evidence का assessment किया जा सकता है।

02 • निष्पक्ष निरीक्षण के बहु-आयामी parameters

🧠 Reasoningpremises, inference, counterexample, causality, uncertainty
📝 NLPliteral, context, temporal, domain, ambiguity, translation
🔎 Evidencesource, provenance, independent verification, counter-evidence
📚 Knowledgeconcepts, numeracy, practical tasks, source literacy
🗣️ Communicationclarity, comprehension, dialogue, uncertainty communication
📄 DocumentsOCR, structure, provenance, integrity/quality indicators
🎧 Audiotranscription and meaning; voice identity is not competence proof
👁️ Visualdocument/image/context quality; no “eye = truth” inference
🫶 Human self-observationself-correction, evidence-vs-experience, reflection
🌍 Nature/Earthenvironmental externalities, resources, long-term risk
🏛️ Public rolepublished duties, law/rules, accountability, public impact
🛡️ Safetyprivacy, cybersecurity, harm minimization, accessibility

03 • Optional sensing — सुरक्षा पहले

Finger-vein, fingerprint, iris/eye, face, voice, liveness, typing dynamics आदि केवल स्पष्ट consent, lawful purpose और आवश्यकता/अनुपातिकता की समीक्षा के बाद।

इन signals से “सच बोलना”, बुद्धिमत्ता, मानसिक अवस्था, चरित्र, धर्म, राजनीतिक पसंद या मानव-मूल्य निकालना app में निषिद्ध रहेगा। Raw biometric data public archive में default रूप से नहीं रखा जाएगा।

04 • सदस्यता / Session Access

Purpose चुनने के बाद assessment session के लिए access state दर्ज होगी। Subscription केवल service access, storage, assessment credits और reports के लिए है; पैसे देकर outcome, certificate या eligibility नहीं बदली जा सकती।

FREE / TRIALप्रारम्भिक self-reflection और सीमित modules
ACTIVEउपलब्ध subscribed assessment modules
PAUSED / EXPIREDनई assessment रोकना; existing records audit policy के अनुसार सुरक्षित
Official/legal certificate तभी माना जाएगा जब संबंधित अधिकृत संस्था वास्तव में उसे जारी करे। AI-generated result अपने-आप VERIFIED नहीं है।

05 • Result pipeline

Purpose → Criteria Version → Consent → Evidence → AI/ML/NLP Analysis → Multi-angle Review → Counter-evidence → Human Review → Report → Appeal → Audit Archive

हर result के साथ evidence, uncertainty, limitations और criteria version दिखेंगे। पुराने result को छिपाकर बदलने के बजाय नया version बनाया जाएगा।
